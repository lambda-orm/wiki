# λORM Labs

The labs are complete, runnable examples of λORM. Most of them are in the
[lambdaorm-labs](https://github.com/lambda-orm/lambdaorm-labs) repository.

## CLI labs

[Using λORM from the command line](https://github.com/lambda-orm/lambdaorm-labs/tree/main/labs/cli) with the
[CLI](../cli/index.md).

## Node.js labs

[Using the `@lambdaorm/lib` package in a Node.js application](https://github.com/lambda-orm/lambdaorm-labs/tree/main/labs/node).

## Engines lab

The [engines lab](https://github.com/lambda-orm/core/tree/main/packages/lib/src/dev/labs/engines) runs the same model,
queries and scripts on PostgreSQL, MySQL, MariaDB, SQL Server, Oracle and MongoDB. See [Engines](../schema/Engines.md).

## Observability lab

The [observability lab](https://github.com/lambda-orm/core/tree/main/packages/lib/src/dev/labs/observability) sends
the logs, metrics and traces of a query over PostgreSQL and MySQL to an OpenTelemetry collector. See
[Observability](../schema/Observability.md).

## Data Gateway

The [Data Gateway](../data-gateway/index.md) section has complete examples of its configuration, its REST, MCP and
WebSocket APIs and its UI; start with [Getting started](../data-gateway/GettingStarted.md).
