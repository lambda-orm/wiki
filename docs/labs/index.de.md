# λORM Labs {#orm-labs}

Die Labs sind vollständige, lauffähige Beispiele für λORM. Die meisten befinden sich im Repository
[lambdaorm-labs](https://github.com/lambda-orm/lambdaorm-labs).

## CLI-Labs {#cli-labs}

[λORM über die Kommandozeile verwenden](https://github.com/lambda-orm/lambdaorm-labs/tree/main/labs/cli) mit der
[CLI](../cli/index.md).

## Node.js-Labs {#nodejs-labs}

[Das Paket `@lambdaorm/lib` in einer Node.js-Anwendung verwenden](https://github.com/lambda-orm/lambdaorm-labs/tree/main/labs/node).

## Engines-Lab {#engines-lab}

Das [Engines-Lab](https://github.com/lambda-orm/core/tree/main/packages/lib/src/dev/labs/engines) führt dasselbe Modell,
dieselben Abfragen und Skripte auf PostgreSQL, MySQL, MariaDB, SQL Server, Oracle und MongoDB aus. Siehe
[Datenbank-Engines](../schema/Engines.md).

## Observability-Lab {#observability-lab}

Das [Observability-Lab](https://github.com/lambda-orm/core/tree/main/packages/lib/src/dev/labs/observability) sendet
die Logs, Metriken und Traces einer Abfrage über PostgreSQL und MySQL an einen OpenTelemetry-Collector. Siehe
[Observability](../schema/Observability.md).

## Data Gateway {#data-gateway}

Der Abschnitt [Data Gateway](../data-gateway/index.md) enthält vollständige Beispiele für seine Konfiguration, seine
REST-, MCP- und WebSocket-APIs und seine UI; beginnen Sie mit [Erste Schritte](../data-gateway/GettingStarted.md).
