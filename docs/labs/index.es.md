# λORM Labs {#orm-labs}

Los labs son ejemplos completos y ejecutables de λORM. La mayoría están en el repositorio
[lambdaorm-labs](https://github.com/lambda-orm/lambdaorm-labs).

## Labs de CLI {#cli-labs}

[Uso de λORM desde la línea de comandos](https://github.com/lambda-orm/lambdaorm-labs/tree/main/labs/cli) con la
[CLI](../cli/index.md).

## Labs de Node.js {#nodejs-labs}

[Uso del paquete `@lambdaorm/lib` en una aplicación Node.js](https://github.com/lambda-orm/lambdaorm-labs/tree/main/labs/node).

## Lab de motores de base de datos {#engines-lab}

El [lab de motores de base de datos](https://github.com/lambda-orm/core/tree/main/packages/lib/src/dev/labs/engines) ejecuta el mismo modelo,
las mismas consultas y los mismos scripts en PostgreSQL, MySQL, MariaDB, SQL Server, Oracle y MongoDB. Véase [Motores de base de datos](../schema/Engines.md).

## Data Gateway {#data-gateway}

La sección [Data Gateway](../data-gateway/index.md) contiene ejemplos completos de su configuración, de sus API REST, MCP y
WebSocket y de su UI; se recomienda empezar por [Primeros pasos](../data-gateway/GettingStarted.md).
