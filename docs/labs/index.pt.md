# Labs do λORM {#orm-labs}

Os labs são exemplos completos e executáveis do λORM. A maioria deles está no repositório
[lambdaorm-labs](https://github.com/lambda-orm/lambdaorm-labs).

## Labs da CLI {#cli-labs}

[Uso do λORM pela linha de comando](https://github.com/lambda-orm/lambdaorm-labs/tree/main/labs/cli) com a
[CLI](../cli/index.md).

## Labs de Node.js {#nodejs-labs}

[Uso do pacote `@lambdaorm/lib` em uma aplicação Node.js](https://github.com/lambda-orm/lambdaorm-labs/tree/main/labs/node).

## Lab de mecanismos de banco de dados {#engines-lab}

O [lab de mecanismos de banco de dados](https://github.com/lambda-orm/core/tree/main/packages/lib/src/dev/labs/engines) executa o mesmo modelo,
as mesmas consultas e os mesmos scripts em PostgreSQL, MySQL, MariaDB, SQL Server, Oracle e MongoDB. Veja [Mecanismos de banco de dados](../schema/Engines.md).

## Data Gateway {#data-gateway}

A seção [Data Gateway](../data-gateway/index.md) traz exemplos completos de sua configuração, de suas APIs REST, MCP e
WebSocket e de sua UI; comece por [Primeiros passos](../data-gateway/GettingStarted.md).
