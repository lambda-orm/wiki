# Join {#join}

Esta página muestra cómo λORM lee propiedades de entidades relacionadas. No hay un método join: cuando una consulta usa una propiedad a través de una relación, como `p.category.name`, λORM añade el join que la relación define en el esquema. El SQL que se muestra es el generado para MySQL.

!!! note "Nota"
    Un join necesita que ambas entidades estén en la misma fuente. Cuando la relación va a una entidad de otra fuente, la misma consulta sigue funcionando: λORM lee cada fuente con su propia sentencia y une las filas en memoria (ver [Consultas entre fuentes](CrossSource.md)). Para cargar las entidades relacionadas como objetos anidados, se usa [Include](Include.md).

## Join simple {#simple-join}

Lee el nombre de cada producto y el nombre de su categoría, a través de la relación `category`.

**Lambda:**

```typescript
Products.map(p => ({ name: p.name, category: p.category.name }))
```

**SQL resultante:**

```sql
SELECT p.ProductName AS name, c.CategoryName AS category
FROM Products p
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
```

## Join con distinct y ordenación {#join-with-distinct-and-sort}

Lee las combinaciones distintas de cantidad por unidad y nombre de categoría, ordenadas por categoría.

**Lambda:**

```typescript
Products
	.distinct(p => ({ quantity: p.quantity, category: p.category.name }))
	.sort(p => p.category)
```

**SQL resultante:**

```sql
SELECT DISTINCT p.QuantityPerUnit AS quantity, c.CategoryName AS category
FROM Products p
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
ORDER BY category asc
```

## Join con filtro {#join-with-filter}

Lee el nombre y la categoría de los productos con un precio mayor que 10.

**Lambda:**

```typescript
Products
	.filter(p => p.price > 10)
	.map(p => ({ name: p.name, category: p.category.name }))
```

**SQL resultante:**

```sql
SELECT p.ProductName AS name, c.CategoryName AS category
FROM Products p
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
WHERE p.UnitPrice > 10
```

## Join y paginación {#join-and-pagination}

Lee el nombre y la categoría de los productos con un precio mayor que 10, ordenados por categoría, y devuelve la primera página de 10 registros.

**Lambda:**

```typescript
Products
	.filter(p => p.price > 10)
	.map(p => ({ name: p.name, category: p.category.name }))
	.sort(p => p.category)
	.page(1, 10)
```

**SQL resultante:**

```sql
SELECT p.ProductName AS name, c.CategoryName AS category
FROM Products p
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
WHERE p.UnitPrice > 10
ORDER BY category asc
LIMIT 0,10
```

## Varios joins y agrupación {#multiple-joins-and-grouping}

Lee, para los pedidos de un cliente, la fecha del pedido y el total (suma de cantidad × precio unitario de sus detalles), ordenados por total en orden descendente. La consulta parte de los detalles del pedido (`Orders.details`) y recorre dos relaciones: `order` y, desde el pedido, `customer`. Como `sum` es una función de agregación, λORM también agrupa por la fecha del pedido (ver [Agrupación](Grouping.md)).

**Lambda:**

```typescript
Orders.details
	.filter(p => p.order.customer.name == customerName)
	.map(p => ({ order: p.order.orderDate, total: sum(p.quantity * p.unitPrice) }))
	.sort(p => desc(p.total))
```

**SQL resultante:**

```sql
SELECT o1.OrderDate AS `order`, SUM((o.Quantity * o.UnitPrice)) AS total
FROM `Order Details` o
INNER JOIN Orders o1 ON o1.OrderID = o.OrderID
INNER JOIN Customers c ON c.CustomerID = o1.CustomerID
WHERE c.CompanyName = ?
GROUP BY o1.OrderDate
ORDER BY total desc
```

## Ejemplo de código {#code-example}

```typescript
import { orm } from '@lambdaorm/lib'
import { Orders } from './domain/model' // model generated by `lambdaorm build`

(async () => {
	try {
		await orm.init('./lambdaORM.yaml')
		const query = (customerName: string) => Orders.details
			.filter(p => p.order.customer.name == customerName)
			.map(p => ({ order: p.order.orderDate, total: sum(p.quantity * p.unitPrice) }))
			.sort(p => desc(p.total))
		const result = await orm.execute(query, { customerName: 'Vins et alcools Chevalier' }, { stage: 'MySQL' })
		console.log(JSON.stringify(result, null, 2))
	} catch (error: any) {
		console.error(error.stack)
	} finally {
		await orm.end()
	}
})()
```
