# Join {#join}

Diese Seite zeigt, wie λORM Eigenschaften verbundener Entitäten liest. Es gibt keine Join-Methode: Wenn eine Abfrage eine Eigenschaft über eine Beziehung verwendet, etwa `p.category.name`, fügt λORM den Join hinzu, den die Beziehung im Schema definiert. Das gezeigte SQL ist das für MySQL erzeugte.

!!! note "Hinweis"
    Ein Join setzt voraus, dass sich beide Entitäten in derselben Quelle befinden. Um verbundene Entitäten aus einer anderen Quelle zu lesen, verwenden Sie [Include](Include.md); um nach einer Eigenschaft einer Beziehung in einer anderen Quelle zu filtern, siehe [Nach einem Feld einer Beziehung in einer anderen Quelle filtern](Include.md#filter-by-a-field-of-a-relation-in-another-source).

## Einfacher Join {#simple-join}

Liest den Namen jedes Produkts und den Namen seiner Kategorie über die Beziehung `category`.

**Lambda:**

```typescript
Products.map(p => ({ name: p.name, category: p.category.name }))
```

**SQL-Ergebnis:**

```sql
SELECT p.ProductName AS name, c.CategoryName AS category
FROM Products p
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
```

## Join mit distinct und Sortierung {#join-with-distinct-and-sort}

Liest die eindeutigen Kombinationen aus Menge pro Einheit und Kategoriename, sortiert nach Kategorie.

**Lambda:**

```typescript
Products
	.distinct(p => ({ quantity: p.quantity, category: p.category.name }))
	.sort(p => p.category)
```

**SQL-Ergebnis:**

```sql
SELECT DISTINCT p.QuantityPerUnit AS quantity, c.CategoryName AS category
FROM Products p
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
ORDER BY category asc
```

## Join mit Filter {#join-with-filter}

Liest Name und Kategorie der Produkte mit einem Preis über 10.

**Lambda:**

```typescript
Products
	.filter(p => p.price > 10)
	.map(p => ({ name: p.name, category: p.category.name }))
```

**SQL-Ergebnis:**

```sql
SELECT p.ProductName AS name, c.CategoryName AS category
FROM Products p
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
WHERE p.UnitPrice > 10
```

## Join und Paginierung {#join-and-pagination}

Liest Name und Kategorie der Produkte mit einem Preis über 10, sortiert nach Kategorie, und gibt die erste Seite mit 10 Datensätzen zurück.

**Lambda:**

```typescript
Products
	.filter(p => p.price > 10)
	.map(p => ({ name: p.name, category: p.category.name }))
	.sort(p => p.category)
	.page(1, 10)
```

**SQL-Ergebnis:**

```sql
SELECT p.ProductName AS name, c.CategoryName AS category
FROM Products p
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
WHERE p.UnitPrice > 10
ORDER BY category asc
LIMIT 0,10
```

## Mehrere Joins und Gruppierung {#multiple-joins-and-grouping}

Liest für die Bestellungen eines Kunden das Bestelldatum und die Gesamtsumme (Summe aus Menge × Stückpreis seiner Positionen), absteigend nach Gesamtsumme sortiert. Die Abfrage beginnt bei den Bestellpositionen (`Orders.details`) und durchläuft zwei Beziehungen: `order` und, von der Bestellung aus, `customer`. Da `sum` eine Aggregatfunktion ist, gruppiert λORM zusätzlich nach dem Bestelldatum (siehe [Grouping](Grouping.md)).

**Lambda:**

```typescript
Orders.details
	.filter(p => p.order.customer.name == customerName)
	.map(p => ({ order: p.order.orderDate, total: sum(p.quantity * p.unitPrice) }))
	.sort(p => desc(p.total))
```

**SQL-Ergebnis:**

```sql
SELECT o1.OrderDate AS `order`, SUM((o.Quantity * o.UnitPrice)) AS total
FROM `Order Details` o
INNER JOIN Orders o1 ON o1.OrderID = o.OrderID
INNER JOIN Customers c ON c.CustomerID = o1.CustomerID
WHERE c.CompanyName = ?
GROUP BY o1.OrderDate
ORDER BY total desc
```

## Codebeispiel {#code-example}

```typescript
import { orm } from '@lambdaorm/lib'
import { Orders } from './domain/model' // model generated by `lambdaorm build`

(async () => {
	try {
		await orm.init('./lambdaORM.yaml')
		const query = (customerName: string) => Orders.details
			.filter(p => p.order.customer.name == customerName)
			.map(p => ({ order: p.order.orderDate, total: sum(p.quantity * p.unitPrice) }))
			.sort(p => desc(p.total))
		const result = await orm.execute(query, { customerName: 'Vins et alcools Chevalier' }, { stage: 'MySQL' })
		console.log(JSON.stringify(result, null, 2))
	} catch (error: any) {
		console.error(error.stack)
	} finally {
		await orm.end()
	}
})()
```
