# Delete {#delete}

Esta página muestra cómo eliminar registros: con un filtro, por clave primaria, todos los registros de una entidad y junto con entidades relacionadas. El SQL que se muestra es el generado para MySQL.

`delete` devuelve el **número de filas afectadas**: `0` significa que ninguna fila cumplió el filtro.

```typescript
const count = await orm.execute('Categories.delete().filter(p => p.id == id)', { id: 9 }) // 1
```

## Eliminar con un filtro {#delete-with-a-filter}

Elimina los detalles de un pedido.

**Lambda:**

```typescript
Orders.details.delete().filter(p => p.orderId === id)
```

**SQL resultante:**

```sql
DELETE o FROM `Order Details` AS o WHERE o.OrderID = ?
```

## Eliminar por clave primaria {#delete-by-primary-key}

Cuando `delete()` no tiene filtro, filtra por la clave primaria, cuyo valor se toma de los datos pasados. La clave primaria de los detalles del pedido está formada por `orderId` y `productId`:

**Lambda:**

```typescript
Orders.details.delete()
```

**SQL resultante:**

```sql
DELETE o FROM `Order Details` AS o WHERE (o.OrderID = ? AND o.ProductID = ?)
```

## Eliminar todos los registros {#delete-all-the-records}

Para eliminar todos los registros de una entidad se usa `deleteAll` en lugar de `delete`. Así se evita eliminar todos los registros por error.

**Lambda:**

```typescript
Orders.details.deleteAll()
```

**SQL resultante:**

```sql
DELETE FROM `Order Details`
```

## Eliminar una entidad y sus entidades relacionadas {#delete-an-entity-and-its-related-entities}

Elimina un pedido y sus detalles. El pedido se filtra por su clave primaria, y cada detalle enviado por su propia clave primaria. Primero se eliminan los detalles y después el pedido.

**Lambda:**

```typescript
Orders.delete().include(p => p.details)
```

**SQL resultante:**

```sql
-- each detail sent, first
DELETE o1 FROM `Order Details` AS o1 WHERE (o1.OrderID = ? AND o1.ProductID = ?)

-- then the order
DELETE o FROM Orders AS o WHERE o.OrderID = ?
```

## Ejemplo de código {#code-example}

Elimina un pedido con sus detalles e imprime el número de pedidos eliminados.

```typescript
import { orm } from '@lambdaorm/lib'
import { Orders } from './domain/model' // model generated by `lambdaorm build`

(async () => {
	try {
		await orm.init('./lambdaORM.yaml')
		const order = {
			id: 1,
			customerId: 'ALFKI',
			employeeId: 6,
			orderDate: '1997-08-24T22:00:00.000Z',
			requiredDate: '1997-09-21T22:00:00.000Z',
			shippedDate: '1997-09-01T22:00:00.000Z',
			shipViaId: 1,
			freight: '29.4600',
			name: 'Alfreds Futterkiste',
			address: 'Obere Str. 57',
			city: 'Berlin',
			region: null,
			postalCode: '12209',
			country: 'Germany',
			details: [
				{
					orderId: 1,
					productId: 28,
					unitPrice: '45.6000',
					quantity: '15.0000',
					discount: '0.0000'
				},
				{
					orderId: 1,
					productId: 39,
					unitPrice: '18.0000',
					quantity: '21.0000',
					discount: '0.0000'
				}
			]
		}
		const query = () => Orders.delete().include(p => p.details)
		// returns the number of orders deleted
		const count = await orm.execute(query, order)
		console.log(count)
	} catch (error: any) {
		console.error(error.stack)
	} finally {
		// releases the connections
		await orm.end()
	}
})()
```
