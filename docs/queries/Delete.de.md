# Löschen {#delete}

Diese Seite zeigt, wie Sie Datensätze löschen: mit einem Filter, über den Primärschlüssel, alle Datensätze einer Entität und zusammen mit verbundenen Entitäten. Das gezeigte SQL ist das für MySQL erzeugte.

`delete` gibt die **Anzahl der betroffenen Zeilen** zurück: `0` bedeutet, dass keine Zeile dem Filter entsprach.

```typescript
const count = await orm.execute('Categories.delete().filter(p => p.id == id)', { id: 9 }) // 1
```

## Löschen mit einem Filter {#delete-with-a-filter}

Löscht die Positionen einer Bestellung.

**Lambda:**

```typescript
Orders.details.delete().filter(p => p.orderId === id)
```

**SQL-Ergebnis:**

```sql
DELETE o FROM `Order Details` AS o WHERE o.OrderID = ?
```

## Löschen über den Primärschlüssel {#delete-by-primary-key}

Hat `delete()` keinen Filter, filtert es nach dem Primärschlüssel, dessen Wert aus den übergebenen Daten genommen wird. Der Primärschlüssel der Bestellpositionen besteht aus `orderId` und `productId`:

**Lambda:**

```typescript
Orders.details.delete()
```

**SQL-Ergebnis:**

```sql
DELETE o FROM `Order Details` AS o WHERE (o.OrderID = ? AND o.ProductID = ?)
```

## Alle Datensätze löschen {#delete-all-the-records}

Um alle Datensätze einer Entität zu löschen, verwenden Sie `deleteAll` statt `delete`. So wird verhindert, dass versehentlich alle Datensätze gelöscht werden.

**Lambda:**

```typescript
Orders.details.deleteAll()
```

**SQL-Ergebnis:**

```sql
DELETE FROM `Order Details`
```

## Eine Entität und ihre verbundenen Entitäten löschen {#delete-an-entity-and-its-related-entities}

Löscht eine Bestellung und ihre Positionen. Die Bestellung wird über ihren Primärschlüssel gefiltert, jede übermittelte Position über ihren eigenen Primärschlüssel. Zuerst werden die Positionen gelöscht, danach die Bestellung.

**Lambda:**

```typescript
Orders.delete().include(p => p.details)
```

**SQL-Ergebnis:**

```sql
-- each detail sent, first
DELETE o1 FROM `Order Details` AS o1 WHERE (o1.OrderID = ? AND o1.ProductID = ?)

-- then the order
DELETE o FROM Orders AS o WHERE o.OrderID = ?
```

## Codebeispiel {#code-example}

Löscht eine Bestellung mit ihren Positionen und gibt die Anzahl der gelöschten Bestellungen aus.

```typescript
import { orm } from '@lambdaorm/lib'
import { Orders } from './domain/model' // model generated by `lambdaorm build`

(async () => {
	try {
		await orm.init('./lambdaORM.yaml')
		const order = {
			id: 1,
			customerId: 'ALFKI',
			employeeId: 6,
			orderDate: '1997-08-24T22:00:00.000Z',
			requiredDate: '1997-09-21T22:00:00.000Z',
			shippedDate: '1997-09-01T22:00:00.000Z',
			shipViaId: 1,
			freight: '29.4600',
			name: 'Alfreds Futterkiste',
			address: 'Obere Str. 57',
			city: 'Berlin',
			region: null,
			postalCode: '12209',
			country: 'Germany',
			details: [
				{
					orderId: 1,
					productId: 28,
					unitPrice: '45.6000',
					quantity: '15.0000',
					discount: '0.0000'
				},
				{
					orderId: 1,
					productId: 39,
					unitPrice: '18.0000',
					quantity: '21.0000',
					discount: '0.0000'
				}
			]
		}
		const query = () => Orders.delete().include(p => p.details)
		// returns the number of orders deleted
		const count = await orm.execute(query, order)
		console.log(count)
	} catch (error: any) {
		console.error(error.stack)
	} finally {
		// releases the connections
		await orm.end()
	}
})()
```
