# Inserción masiva {#bulk-insert}

Esta página muestra cómo insertar muchos registros a la vez con `bulkInsert`. Se usa en lugar de [Insert](Insert.md) cuando hay que cargar una lista de registros, por ejemplo en una importación o con un conjunto de datos grande. El SQL que se muestra es el generado para MySQL.

`bulkInsert` recibe un array de registros y los inserta por lotes, con una sentencia por lote en lugar de una sentencia por registro. El tamaño de los lotes depende de la conexión y se puede reducir con la opción `chunkSize` de `orm.execute`. Así se reducen los viajes de ida y vuelta entre la aplicación y la base de datos, lo que hace mucho más rápida la inserción de grandes volúmenes de datos y alivia la carga del servidor de base de datos.

## Inserción masiva en una entidad {#bulk-insert-into-one-entity}

Inserta una lista de categorías.

**Lambda:**

```typescript
Categories.bulkInsert()
```

**SQL resultante:**

```sql
INSERT INTO Categories(CategoryName,Description) VALUES ?
```

## Inserción masiva con una entidad relacionada {#bulk-insert-with-a-related-entity}

Inserta una lista de pedidos, cada uno con sus detalles.

**Lambda:**

```typescript
Orders.bulkInsert().include(p => p.details)
```

**SQL resultante:**

```sql
-- the orders
INSERT INTO Orders(CustomerID,EmployeeID,OrderDate,RequiredDate,ShippedDate,ShipVia,Freight,ShipName,ShipAddress,ShipCity,ShipRegion,ShipPostalCode,ShipCountry) VALUES ?

-- the details of all the orders
INSERT INTO `Order Details`(OrderID,ProductID,UnitPrice,Quantity,Discount) VALUES ?
```

## Ejemplo de código {#code-example}

Inserta dos categorías e imprime los ids de los registros insertados.

```typescript
import { orm } from '@lambdaorm/lib'
import { Categories } from './domain/model' // model generated by `lambdaorm build`

(async () => {
	try {
		await orm.init('./lambdaORM.yaml')
		const categories = [
			{ name: 'Beverages4', description: 'Soft drinks, coffees, teas, beers, and ales' },
			{ name: 'Condiments4', description: 'Sweet and savory sauces, relishes, spreads, and seasonings' }
		]
		const query = () => Categories.bulkInsert()
		// returns the ids of the records inserted
		const result = await orm.execute(query, categories)
		console.log(JSON.stringify(result, null, 2))
	} catch (error: any) {
		console.error(error.stack)
	} finally {
		// releases the connections
		await orm.end()
	}
})()
```
