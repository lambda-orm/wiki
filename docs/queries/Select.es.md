# Select {#select}

Esta página muestra cómo leer registros: todas las propiedades de una entidad o solo algunas, el primer o el último registro, valores distintos y paginación. El SQL que se muestra es el generado para MySQL.

Toda consulta se basa en el esquema, del que λORM conoce las propiedades de cada entidad, su clave primaria, índices, relaciones y restricciones. Por eso, para leer todas las propiedades de una entidad, no hace falta enumerarlas.

## Todas las propiedades de una entidad {#all-the-properties-of-an-entity}

Lee todas las propiedades de todos los productos.

**Lambda:**

```typescript
Products
```

**SQL resultante:**

```sql
SELECT
    p.ProductID AS id,
    p.ProductName AS name,
    p.SupplierID AS supplierId,
    p.CategoryID AS categoryId,
    p.QuantityPerUnit AS quantity,
    p.UnitPrice AS price,
    p.UnitsInStock AS inStock,
    p.UnitsOnOrder AS onOrder,
    p.ReorderLevel AS reorderLevel,
    p.Discontinued AS discontinued
FROM Products p
```

## Una propiedad {#one-property}

Lee solo el nombre de cada producto.

**Lambda:**

```typescript
Products.map(p => p.name)
```

**SQL resultante:**

```sql
SELECT p.ProductName AS name FROM Products p
```

## First {#first}

Lee el primer producto, ordenado por su clave primaria.

**Lambda:**

```typescript
Products.first()
```

**SQL resultante:**

```sql
SELECT
    p.ProductID AS id,
    p.ProductName AS name,
    p.SupplierID AS supplierId,
    p.CategoryID AS categoryId,
    p.QuantityPerUnit AS quantity,
    p.UnitPrice AS price,
    p.UnitsInStock AS inStock,
    p.UnitsOnOrder AS onOrder,
    p.ReorderLevel AS reorderLevel,
    p.Discontinued AS discontinued
FROM Products p
ORDER BY p.ProductID asc
LIMIT 0,1
```

`first` también puede recibir las propiedades a devolver, como hace `map`: `Products.first(p => ({ name: p.name, price: p.price }))`. En ese caso los registros se ordenan por la primera propiedad devuelta.

## Last {#last}

Lee el último producto, ordenado por su clave primaria.

**Lambda:**

```typescript
Products.last()
```

**SQL resultante:**

```sql
SELECT
    p.ProductID AS id,
    p.ProductName AS name,
    p.SupplierID AS supplierId,
    p.CategoryID AS categoryId,
    p.QuantityPerUnit AS quantity,
    p.UnitPrice AS price,
    p.UnitsInStock AS inStock,
    p.UnitsOnOrder AS onOrder,
    p.ReorderLevel AS reorderLevel,
    p.Discontinued AS discontinued
FROM Products p
ORDER BY p.ProductID desc
LIMIT 0,1
```

## Distinct {#distinct}

Lee las combinaciones distintas de cantidad por unidad y nombre de categoría, ordenadas por categoría. El nombre de la categoría viene de la relación `category`, por lo que λORM añade el join (ver [Join](Join.md)).

**Lambda:**

```typescript
Products
	.distinct(p => ({ quantity: p.quantity, category: p.category.name }))
	.sort(p => p.category)
```

**SQL resultante:**

```sql
SELECT DISTINCT p.QuantityPerUnit AS quantity, c.CategoryName AS category
FROM Products p
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
ORDER BY category asc
```

## Paginación {#pagination}

Lee el nombre y la categoría de los productos con un precio mayor que 10, ordenados por categoría, y devuelve la primera página de 10 registros.

**Lambda:**

```typescript
Products
	.filter(p => p.price > 10)
	.map(p => ({ name: p.name, category: p.category.name }))
	.sort(p => p.category)
	.page(1, 10)
```

**SQL resultante:**

```sql
SELECT p.ProductName AS name, c.CategoryName AS category
FROM Products p
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
WHERE p.UnitPrice > 10
ORDER BY category asc
LIMIT 0,10
```

`page(page, records)` recibe el número de página (empezando en 1) y el número de registros por página. Cómo se expresa la página depende del dialecto: `LIMIT` en MySQL, `OFFSET … FETCH NEXT … ROWS ONLY` en Oracle, etc.

## Uso {#usage}

La misma consulta, con el precio mínimo como parámetro (`minPrice`), ejecutada de tres formas.

### Node {#node}

Con la librería [`@lambdaorm/lib`](../usage/Usage.md):

```typescript
import { orm } from '@lambdaorm/lib'
import { Products } from './domain/model' // model generated by `lambdaorm build`

(async () => {
	try {
		await orm.init('./lambdaORM.yaml')
		// products with a price greater than minPrice, with their category, first page of 10
		const query = (minPrice: number) => Products
			.filter(p => p.price > minPrice)
			.map(p => ({ name: p.name, category: p.category.name }))
			.sort(p => p.category)
			.page(1, 10)
		const result = await orm.execute(query, { minPrice: 10 })
		console.log(JSON.stringify(result, null, 2))
	} catch (error: any) {
		console.error(error.stack)
	} finally {
		// releases the connections
		await orm.end()
	}
})()
```

### CLI {#cli}

Con la [CLI](../cli/index.md) `@lambdaorm/cli`:

```sh
lambdaorm execute -q "Products.filter(p=>p.price>minPrice).map(p=>({name:p.name,category:p.category.name})).sort(p=>p.category).page(1,10)" -d "{\"minPrice\":10}"
```

### Data Gateway {#data-gateway}

A través de la [API REST](../data-gateway/Rest.md) del [Data Gateway](../data-gateway/index.md):

```sh
curl -X POST "http://localhost:8080/execute?format=beautiful" -H "X-Api-Key: $KEY" -H "Content-Type: application/json" \
  -d '{"query": "Products.filter(p=>p.price>minPrice).map(p=>({name:p.name,category:p.category.name})).sort(p=>p.category).page(1,10)", "data": {"minPrice": 10}}'
```
