# Metadatos {#metadata}

Esta página describe los métodos que analizan una consulta sin ejecutarla: los parámetros que necesita, la forma de su resultado, las restricciones que se aplican, su árbol analizado y las sentencias que ejecutaría. Sirven para validar una consulta, para construir un formulario o un tipo para sus datos, o para ver el SQL que genera λORM.

Estos métodos no acceden a la base de datos, por lo que no se necesitan las conexiones: se puede llamar a `orm.init(schema, false)` para cargar el esquema sin conectarse.

| Método | Descripción |
|:--|:--|
| `orm.parameters(query)` | Las variables que usa la consulta (que van en `data`), con sus tipos. |
| `orm.model(query)` | Las propiedades del resultado, con sus tipos. |
| `orm.constraints(query)` | Las restricciones que se aplican a las entidades de la consulta. |
| `orm.metadata(query)` | El árbol analizado de la consulta: cada sentencia con su entidad, columnas, parámetros y restricciones. |
| `orm.plan(query, options?)` | Cómo se ejecuta la consulta: el dialecto, la fuente y la sentencia de cada parte. `options.stage` selecciona el stage. |
| `orm.normalize(query)` | La consulta en su forma completa, por ejemplo con las propiedades de `map` explícitas. |

La consulta puede ser una función lambda o un string. La misma información está disponible desde la [CLI](../cli/index.md) (`lambdaorm parameters`, `model`, `constraints`, `metadata`, `plan`) y desde el [Data Gateway](../data-gateway/Rest.md) (`POST /parameters`, `/model`, `/constraints`, `/metadata`, `/plan`).

## Ejemplo {#example}

```typescript
import { orm } from '@lambdaorm/lib'
import { Orders } from './domain/model' // model generated by `lambdaorm build`

(async () => {
	try {
		// load the schema without connecting to the databases
		await orm.init('./lambdaORM.yaml', false)
		const query = (id: number) => Orders
			.filter(p => p.id === id)
			.include(p => p.details)
			.map(p => ({ name: p.orderDate, customer: p.customer.name }))

		console.log(JSON.stringify(orm.parameters(query), null, 2))
		console.log(JSON.stringify(orm.model(query), null, 2))
		console.log(JSON.stringify(orm.constraints(query), null, 2))
		console.log(JSON.stringify(orm.metadata(query), null, 2))
		console.log(JSON.stringify(orm.plan(query, { stage: 'MySQL' }), null, 2))
	} catch (error: any) {
		console.error(error)
	} finally {
		await orm.end()
	}
})()
```

## Resultados {#results}

Los resultados incluyen `LambdaOrmParentId`, la clave interna que λORM usa para vincular los detalles con su pedido (ver [Include](Include.md)).

### Parámetros {#parameters}

La consulta necesita `id`, un entero:

```json
[
  { "name": "id", "type": "integer" },
  {
    "name": "details",
    "type": "Orders.details",
    "children": [
      { "name": "LambdaOrmParentId", "type": "[integer]" }
    ]
  }
]
```

### Modelo {#model}

Cada pedido del resultado tiene `name`, `customer` y el array `details`:

```json
[
  { "name": "name", "type": "dateTime" },
  { "name": "customer", "type": "string" },
  {
    "name": "details",
    "type": "Orders.details[]",
    "children": [
      { "name": "orderId", "type": "integer" },
      { "name": "productId", "type": "integer" },
      { "name": "unitPrice", "type": "decimal" },
      { "name": "quantity", "type": "decimal" },
      { "name": "discount", "type": "decimal" },
      { "name": "LambdaOrmParentId", "type": "integer" }
    ]
  }
]
```

### Restricciones {#constraints}

```json
{
  "entity": "Orders",
  "constraints": [],
  "children": [
    { "entity": "Orders.details", "constraints": [] }
  ]
}
```

### Metadatos {#metadata}

Una sentencia para los pedidos y, como hija, una para los detalles (se omiten los campos `pos`):

```json
{
  "classtype": "Sentence",
  "name": "select",
  "type": "any",
  "entity": "Orders",
  "alias": "o",
  "clause": "select",
  "columns": [
    { "name": "name", "type": "dateTime" },
    { "name": "customer", "type": "string" },
    { "name": "__id", "type": "integer" }
  ],
  "parameters": [{ "name": "id", "type": "integer" }],
  "constraints": [],
  "values": [],
  "defaults": [],
  "children": [
    {
      "classtype": "Sentence",
      "name": "select",
      "type": "any",
      "entity": "Orders.details",
      "alias": "o1",
      "clause": "select",
      "columns": [
        { "name": "orderId", "type": "integer" },
        { "name": "productId", "type": "integer" },
        { "name": "unitPrice", "type": "decimal" },
        { "name": "quantity", "type": "decimal" },
        { "name": "discount", "type": "decimal" },
        { "name": "LambdaOrmParentId", "type": "integer" }
      ],
      "parameters": [{ "name": "LambdaOrmParentId", "type": "any" }],
      "constraints": [],
      "values": [],
      "defaults": [],
      "children": []
    }
  ]
}
```

### Plan {#plan}

```json
{
  "entity": "Orders",
  "dialect": "MySQL",
  "source": "MySQL",
  "sentence": "SELECT o.OrderDate AS name, c.CompanyName AS customer, o.OrderID AS `__id` FROM Orders o INNER JOIN Customers c ON c.CustomerID = o.CustomerID WHERE o.OrderID = ? ",
  "children": [
    {
      "entity": "Orders.details",
      "dialect": "MySQL",
      "source": "MySQL",
      "sentence": "SELECT o1.OrderID AS orderId, o1.ProductID AS productId, o1.UnitPrice AS unitPrice, o1.Quantity AS quantity, o1.Discount AS discount, o1.OrderID AS LambdaOrmParentId FROM `Order Details` o1  WHERE  o1.OrderID IN (?) "

  ]

```
