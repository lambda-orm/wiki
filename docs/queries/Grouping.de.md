# Gruppierung {#grouping}

Diese Seite zeigt, wie Sie Datensätze gruppieren und Aggregate berechnen (Summen, Anzahlen, Maxima …) und wie Sie die Gruppen mit `having` filtern. Das gezeigte SQL ist das für MySQL erzeugte.

Die Gruppierung wird nicht deklariert: λORM leitet sie ab, wenn die Abfrage eine Aggregatfunktion verwendet. Die Datensätze werden nach den zurückgegebenen Eigenschaften gruppiert, die nicht innerhalb einer Aggregatfunktion stehen.

## Aggregatfunktionen {#aggregate-functions}

| Funktion | Beschreibung |
|:--|:--|
| avg | Berechnet den Durchschnitt der Werte einer Gruppe. |
| count | Zählt die Datensätze einer Gruppe. |
| first | Gibt den ersten Wert einer Gruppe zurück. |
| last | Gibt den letzten Wert einer Gruppe zurück. |
| max | Berechnet das Maximum. |
| min | Berechnet das Minimum. |
| sum | Berechnet die Summe. |

## Summe mit Filter und Sortierung {#sum-with-filter-and-sort}

Liest für die Bestellungen eines Kunden das Bestelldatum und die Gesamtsumme (Summe aus Menge × Stückpreis), absteigend nach Gesamtsumme sortiert. Die Datensätze werden nach `order` gruppiert, der einzigen zurückgegebenen Eigenschaft, die kein Aggregat ist.

**Lambda:**

```typescript
Orders.details
	.filter(p => p.order.customer.name == customerName)
	.map(p => ({ order: p.order.orderDate, total: sum(p.quantity * p.unitPrice) }))
	.sort(p => desc(p.total))
```

**SQL-Ergebnis:**

```sql
SELECT o1.OrderDate AS `order`, SUM((o.Quantity * o.UnitPrice)) AS total
FROM `Order Details` o
INNER JOIN Orders o1 ON o1.OrderID = o.OrderID
INNER JOIN Customers c ON c.CustomerID = o1.CustomerID
WHERE c.CompanyName = ?
GROUP BY o1.OrderDate
ORDER BY total desc
```

## Gruppierung und having {#grouping-and-having}

Liest den höchsten Preis jeder Kategorie und berücksichtigt dabei die Produkte mit einem Preis über 5, deren Lieferant aus einem bestimmten Land stammt, oder mit weniger als 3 Einheiten auf Lager. Zurückgegeben werden nur die Kategorien, deren höchster Preis über 50 liegt, absteigend nach diesem Preis sortiert.

`filter` wird vor der Gruppierung auf die Datensätze angewendet (WHERE); `having` wird auf die Gruppen angewendet (HAVING).

**Lambda:**

```typescript
Products
	.filter(p => (p.price > 5 && p.supplier.country == country) || (p.inStock < 3))
	.having(p => max(p.price) > 50)
	.map(p => ({ category: p.category.name, largestPrice: max(p.price) }))
	.sort(p => desc(p.largestPrice))
```

**SQL-Ergebnis:**

```sql
SELECT c.CategoryName AS category, MAX(p.UnitPrice) AS largestPrice
FROM Products p
INNER JOIN Suppliers s ON s.SupplierID = p.SupplierID
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
WHERE ((p.UnitPrice > 5 AND s.Country = ?) OR p.UnitsInStock < 3)
GROUP BY c.CategoryName
HAVING MAX(p.UnitPrice) > 50
ORDER BY largestPrice desc
```

## Codebeispiel {#code-example}

```typescript
import { orm } from '@lambdaorm/lib'
import { Products } from './domain/model' // model generated by `lambdaorm build`

(async () => {
	try {
		await orm.init('./lambdaORM.yaml')
		// highest price per category, for the categories whose highest price is greater than 50
		const query = (country: string) => Products
			.filter(p => (p.price > 5 && p.supplier.country == country) || (p.inStock < 3))
			.having(p => max(p.price) > 50)
			.map(p => ({ category: p.category.name, largestPrice: max(p.price) }))
			.sort(p => desc(p.largestPrice))
		const result = await orm.execute(query, { country: 'USA' })
		console.log(JSON.stringify(result, null, 2))
	} catch (error: any) {
		console.error(error.stack)
	} finally {
		// releases the connections
		await orm.end()
	}
})()
```
