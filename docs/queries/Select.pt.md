# Select {#select}

Esta página mostra como ler registros: todas as propriedades de uma entidade ou apenas algumas, o primeiro ou o último registro, valores distintos e paginação. O SQL mostrado é o gerado para MySQL.

Toda consulta se baseia no esquema, a partir do qual o λORM conhece as propriedades de cada entidade, sua chave primária, índices, relações e restrições. Por isso, para ler todas as propriedades de uma entidade, não é necessário listá-las.

## Todas as propriedades de uma entidade {#all-the-properties-of-an-entity}

Lê todas as propriedades de todos os produtos.

**Lambda:**

```typescript
Products
```

**Resultado SQL:**

```sql
SELECT
    p.ProductID AS id,
    p.ProductName AS name,
    p.SupplierID AS supplierId,
    p.CategoryID AS categoryId,
    p.QuantityPerUnit AS quantity,
    p.UnitPrice AS price,
    p.UnitsInStock AS inStock,
    p.UnitsOnOrder AS onOrder,
    p.ReorderLevel AS reorderLevel,
    p.Discontinued AS discontinued
FROM Products p
```

## Uma propriedade {#one-property}

Lê apenas o nome de cada produto.

**Lambda:**

```typescript
Products.map(p => p.name)
```

**Resultado SQL:**

```sql
SELECT p.ProductName AS name FROM Products p
```

## Primeiro {#first}

Lê o primeiro produto, ordenado pela sua chave primária.

**Lambda:**

```typescript
Products.first()
```

**Resultado SQL:**

```sql
SELECT
    p.ProductID AS id,
    p.ProductName AS name,
    p.SupplierID AS supplierId,
    p.CategoryID AS categoryId,
    p.QuantityPerUnit AS quantity,
    p.UnitPrice AS price,
    p.UnitsInStock AS inStock,
    p.UnitsOnOrder AS onOrder,
    p.ReorderLevel AS reorderLevel,
    p.Discontinued AS discontinued
FROM Products p
ORDER BY p.ProductID asc
LIMIT 0,1
```

`first` também pode receber as propriedades a retornar, como faz `map`: `Products.first(p => ({ name: p.name, price: p.price }))`. Nesse caso, os registros são ordenados pela primeira propriedade retornada.

## Último {#last}

Lê o último produto, ordenado pela sua chave primária.

**Lambda:**

```typescript
Products.last()
```

**Resultado SQL:**

```sql
SELECT
    p.ProductID AS id,
    p.ProductName AS name,
    p.SupplierID AS supplierId,
    p.CategoryID AS categoryId,
    p.QuantityPerUnit AS quantity,
    p.UnitPrice AS price,
    p.UnitsInStock AS inStock,
    p.UnitsOnOrder AS onOrder,
    p.ReorderLevel AS reorderLevel,
    p.Discontinued AS discontinued
FROM Products p
ORDER BY p.ProductID desc
LIMIT 0,1
```

## Distinct {#distinct}

Lê as combinações distintas de quantidade por unidade e nome da categoria, ordenadas por categoria. O nome da categoria vem da relação `category`, por isso o λORM adiciona o join (veja [Join](Join.md)).

**Lambda:**

```typescript
Products
	.distinct(p => ({ quantity: p.quantity, category: p.category.name }))
	.sort(p => p.category)
```

**Resultado SQL:**

```sql
SELECT DISTINCT p.QuantityPerUnit AS quantity, c.CategoryName AS category
FROM Products p
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
ORDER BY category asc
```

## Paginação {#pagination}

Lê o nome e a categoria dos produtos com preço maior que 10, ordenados por categoria, e retorna a primeira página de 10 registros.

**Lambda:**

```typescript
Products
	.filter(p => p.price > 10)
	.map(p => ({ name: p.name, category: p.category.name }))
	.sort(p => p.category)
	.page(1, 10)
```

**Resultado SQL:**

```sql
SELECT p.ProductName AS name, c.CategoryName AS category
FROM Products p
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
WHERE p.UnitPrice > 10
ORDER BY category asc
LIMIT 0,10
```

`page(page, records)` recebe o número da página (começando em 1) e o número de registros por página. A forma de expressar a página depende do dialeto: `LIMIT` no MySQL, `OFFSET … FETCH NEXT … ROWS ONLY` no Oracle, e assim por diante.

## Uso {#usage}

A mesma consulta, com o preço mínimo como parâmetro (`minPrice`), executada de três formas.

### Node {#node}

Com a biblioteca [`@lambdaorm/lib`](../usage/Usage.md):

```typescript
import { orm } from '@lambdaorm/lib'
import { Products } from './domain/model' // model generated by `lambdaorm build`

(async () => {
	try {
		await orm.init('./lambdaORM.yaml')
		// products with a price greater than minPrice, with their category, first page of 10
		const query = (minPrice: number) => Products
			.filter(p => p.price > minPrice)
			.map(p => ({ name: p.name, category: p.category.name }))
			.sort(p => p.category)
			.page(1, 10)
		const result = await orm.execute(query, { minPrice: 10 })
		console.log(JSON.stringify(result, null, 2))
	} catch (error: any) {
		console.error(error.stack)
	} finally {
		// releases the connections
		await orm.end()
	}
})()
```

### CLI {#cli}

Com a [CLI](../cli/index.md) `@lambdaorm/cli`:

```sh
lambdaorm execute -q "Products.filter(p=>p.price>minPrice).map(p=>({name:p.name,category:p.category.name})).sort(p=>p.category).page(1,10)" -d "{\"minPrice\":10}"
```

### Data Gateway {#data-gateway}

Através da [API REST](../data-gateway/Rest.md) do [Data Gateway](../data-gateway/index.md):

```sh
curl -X POST "http://localhost:8080/execute?format=beautiful" -H "X-Api-Key: $KEY" -H "Content-Type: application/json" \
  -d '{"query": "Products.filter(p=>p.price>minPrice).map(p=>({name:p.name,category:p.category.name})).sort(p=>p.category).page(1,10)", "data": {"minPrice": 10}}'
```
