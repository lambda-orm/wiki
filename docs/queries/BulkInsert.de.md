# Masseneinfügung {#bulk-insert}

Diese Seite zeigt, wie Sie mit `bulkInsert` viele Datensätze auf einmal einfügen. Verwenden Sie es anstelle von [Insert](Insert.md), wenn Sie eine Liste von Datensätzen laden möchten, etwa bei einem Import oder einem großen Datenbestand. Das gezeigte SQL ist das für MySQL erzeugte.

`bulkInsert` erhält ein Array von Datensätzen und fügt sie in Blöcken ein, mit einer Anweisung pro Block statt einer Anweisung pro Datensatz. Die Größe der Blöcke hängt von der Verbindung ab; Sie können sie mit der Option `chunkSize` von `orm.execute` verringern. Dadurch sinkt die Zahl der Roundtrips zwischen Anwendung und Datenbank, was das Einfügen großer Datenmengen deutlich beschleunigt und den Datenbankserver entlastet.

## Masseneinfügung in eine Entität {#bulk-insert-into-one-entity}

Fügt eine Liste von Kategorien ein.

**Lambda:**

```typescript
Categories.bulkInsert()
```

**SQL-Ergebnis:**

```sql
INSERT INTO Categories(CategoryName,Description) VALUES ?
```

## Masseneinfügung mit einer verbundenen Entität {#bulk-insert-with-a-related-entity}

Fügt eine Liste von Bestellungen ein, jede mit ihren Positionen.

**Lambda:**

```typescript
Orders.bulkInsert().include(p => p.details)
```

**SQL-Ergebnis:**

```sql
-- the orders
INSERT INTO Orders(CustomerID,EmployeeID,OrderDate,RequiredDate,ShippedDate,ShipVia,Freight,ShipName,ShipAddress,ShipCity,ShipRegion,ShipPostalCode,ShipCountry) VALUES ?

-- the details of all the orders
INSERT INTO `Order Details`(OrderID,ProductID,UnitPrice,Quantity,Discount) VALUES ?
```

## Codebeispiel {#code-example}

Fügt zwei Kategorien ein und gibt die IDs der eingefügten Datensätze aus.

```typescript
import { orm } from '@lambdaorm/lib'
import { Categories } from './domain/model' // model generated by `lambdaorm build`

(async () => {
	try {
		await orm.init('./lambdaORM.yaml')
		const categories = [
			{ name: 'Beverages4', description: 'Soft drinks, coffees, teas, beers, and ales' },
			{ name: 'Condiments4', description: 'Sweet and savory sauces, relishes, spreads, and seasonings' }
		]
		const query = () => Categories.bulkInsert()
		// returns the ids of the records inserted
		const result = await orm.execute(query, categories)
		console.log(JSON.stringify(result, null, 2))
	} catch (error: any) {
		console.error(error.stack)
	} finally {
		// releases the connections
		await orm.end()
	}
})()
```
