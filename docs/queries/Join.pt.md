# Join {#join}

Esta página mostra como o λORM lê propriedades de entidades relacionadas. Não há um método join: quando uma consulta usa uma propriedade através de uma relação, como `p.category.name`, o λORM adiciona o join que a relação define no esquema. O SQL mostrado é o gerado para MySQL.

!!! note "Nota"
    Um join precisa que as duas entidades estejam na mesma fonte. Para ler entidades relacionadas que estão em outra fonte, use [Include](Include.md); para filtrar por uma propriedade de uma relação em outra fonte, veja [Filtrar por um campo de uma relação em outra fonte](Include.md#filter-by-a-field-of-a-relation-in-another-source).

## Join simples {#simple-join}

Lê o nome de cada produto e o nome da sua categoria, através da relação `category`.

**Lambda:**

```typescript
Products.map(p => ({ name: p.name, category: p.category.name }))
```

**Resultado SQL:**

```sql
SELECT p.ProductName AS name, c.CategoryName AS category
FROM Products p
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
```

## Join com distinct e ordenação {#join-with-distinct-and-sort}

Lê as combinações distintas de quantidade por unidade e nome da categoria, ordenadas por categoria.

**Lambda:**

```typescript
Products
	.distinct(p => ({ quantity: p.quantity, category: p.category.name }))
	.sort(p => p.category)
```

**Resultado SQL:**

```sql
SELECT DISTINCT p.QuantityPerUnit AS quantity, c.CategoryName AS category
FROM Products p
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
ORDER BY category asc
```

## Join com filtro {#join-with-filter}

Lê o nome e a categoria dos produtos com preço maior que 10.

**Lambda:**

```typescript
Products
	.filter(p => p.price > 10)
	.map(p => ({ name: p.name, category: p.category.name }))
```

**Resultado SQL:**

```sql
SELECT p.ProductName AS name, c.CategoryName AS category
FROM Products p
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
WHERE p.UnitPrice > 10
```

## Join e paginação {#join-and-pagination}

Lê o nome e a categoria dos produtos com preço maior que 10, ordenados por categoria, e retorna a primeira página de 10 registros.

**Lambda:**

```typescript
Products
	.filter(p => p.price > 10)
	.map(p => ({ name: p.name, category: p.category.name }))
	.sort(p => p.category)
	.page(1, 10)
```

**Resultado SQL:**

```sql
SELECT p.ProductName AS name, c.CategoryName AS category
FROM Products p
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
WHERE p.UnitPrice > 10
ORDER BY category asc
LIMIT 0,10
```

## Múltiplos joins e agrupamento {#multiple-joins-and-grouping}

Lê, para os pedidos de um cliente, a data do pedido e o total (soma de quantidade × preço unitário dos seus detalhes), ordenados pelo total em ordem decrescente. A consulta parte dos detalhes do pedido (`Orders.details`) e passa por duas relações: `order` e, a partir do pedido, `customer`. Como `sum` é uma função de agregação, o λORM também agrupa pela data do pedido (veja [Agrupamento](Grouping.md)).

**Lambda:**

```typescript
Orders.details
	.filter(p => p.order.customer.name == customerName)
	.map(p => ({ order: p.order.orderDate, total: sum(p.quantity * p.unitPrice) }))
	.sort(p => desc(p.total))
```

**Resultado SQL:**

```sql
SELECT o1.OrderDate AS `order`, SUM((o.Quantity * o.UnitPrice)) AS total
FROM `Order Details` o
INNER JOIN Orders o1 ON o1.OrderID = o.OrderID
INNER JOIN Customers c ON c.CustomerID = o1.CustomerID
WHERE c.CompanyName = ?
GROUP BY o1.OrderDate
ORDER BY total desc
```

## Exemplo de código {#code-example}

```typescript
import { orm } from '@lambdaorm/lib'
import { Orders } from './domain/model' // model generated by `lambdaorm build`

(async () => {
	try {
		await orm.init('./lambdaORM.yaml')
		const query = (customerName: string) => Orders.details
			.filter(p => p.order.customer.name == customerName)
			.map(p => ({ order: p.order.orderDate, total: sum(p.quantity * p.unitPrice) }))
			.sort(p => desc(p.total))
		const result = await orm.execute(query, { customerName: 'Vins et alcools Chevalier' }, { stage: 'MySQL' })
		console.log(JSON.stringify(result, null, 2))
	} catch (error: any) {
		console.error(error.stack)
	} finally {
		await orm.end()
	}
})()
```
