# Agrupación {#grouping}

Esta página muestra cómo agrupar registros y calcular agregados (sumas, conteos, máximos…), y cómo filtrar los grupos con `having`. El SQL que se muestra es el generado para MySQL.

La agrupación no se declara: λORM la deduce cuando la consulta usa una función de agregación. Los registros se agrupan por las propiedades devueltas que no están dentro de una función de agregación.

## Funciones de agregación {#aggregate-functions}

| Función | Descripción |
|:--|:--|
| avg | Calcula el promedio de los valores de un grupo. |
| count | Cuenta los registros de un grupo. |
| first | Devuelve el primer valor de un grupo. |
| last | Devuelve el último valor de un grupo. |
| max | Calcula el máximo. |
| min | Calcula el mínimo. |
| sum | Calcula la suma. |

## Suma con filtro y ordenación {#sum-with-filter-and-sort}

Lee, para los pedidos de un cliente, la fecha del pedido y el total (suma de cantidad × precio unitario), ordenados por total en orden descendente. Los registros se agrupan por `order`, la única propiedad devuelta que no es un agregado.

**Lambda:**

```typescript
Orders.details
	.filter(p => p.order.customer.name == customerName)
	.map(p => ({ order: p.order.orderDate, total: sum(p.quantity * p.unitPrice) }))
	.sort(p => desc(p.total))
```

**SQL resultante:**

```sql
SELECT o1.OrderDate AS `order`, SUM((o.Quantity * o.UnitPrice)) AS total
FROM `Order Details` o
INNER JOIN Orders o1 ON o1.OrderID = o.OrderID
INNER JOIN Customers c ON c.CustomerID = o1.CustomerID
WHERE c.CompanyName = ?
GROUP BY o1.OrderDate
ORDER BY total desc
```

## Agrupación y having {#grouping-and-having}

Lee el precio más alto de cada categoría, considerando los productos con un precio mayor que 5 cuyo proveedor es de un país dado, o con menos de 3 unidades en stock. Solo se devuelven las categorías cuyo precio más alto es mayor que 50, ordenadas por ese precio en orden descendente.

`filter` se aplica a los registros antes de agrupar (WHERE); `having` se aplica a los grupos (HAVING).

**Lambda:**

```typescript
Products
	.filter(p => (p.price > 5 && p.supplier.country == country) || (p.inStock < 3))
	.having(p => max(p.price) > 50)
	.map(p => ({ category: p.category.name, largestPrice: max(p.price) }))
	.sort(p => desc(p.largestPrice))
```

**SQL resultante:**

```sql
SELECT c.CategoryName AS category, MAX(p.UnitPrice) AS largestPrice
FROM Products p
INNER JOIN Suppliers s ON s.SupplierID = p.SupplierID
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
WHERE ((p.UnitPrice > 5 AND s.Country = ?) OR p.UnitsInStock < 3)
GROUP BY c.CategoryName
HAVING MAX(p.UnitPrice) > 50
ORDER BY largestPrice desc
```

## Ejemplo de código {#code-example}

```typescript
import { orm } from '@lambdaorm/lib'
import { Products } from './domain/model' // model generated by `lambdaorm build`

(async () => {
	try {
		await orm.init('./lambdaORM.yaml')
		// highest price per category, for the categories whose highest price is greater than 50
		const query = (country: string) => Products
			.filter(p => (p.price > 5 && p.supplier.country == country) || (p.inStock < 3))
			.having(p => max(p.price) > 50)
			.map(p => ({ category: p.category.name, largestPrice: max(p.price) }))
			.sort(p => desc(p.largestPrice))
		const result = await orm.execute(query, { country: 'USA' })
		console.log(JSON.stringify(result, null, 2))
	} catch (error: any) {
		console.error(error.stack)
	} finally {
		// releases the connections
		await orm.end()
	}
})()
```
