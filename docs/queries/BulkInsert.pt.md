# Inserção em massa {#bulk-insert}

Esta página mostra como inserir muitos registros de uma só vez com `bulkInsert`. Use-o em vez de [Insert](Insert.md) quando houver uma lista de registros a carregar, como em uma importação ou em um grande conjunto de dados. O SQL mostrado é o gerado para MySQL.

`bulkInsert` recebe um array de registros e os insere em lotes, com uma sentença por lote em vez de uma sentença por registro. O tamanho dos lotes depende da conexão, e é possível reduzi-lo com a opção `chunkSize` de `orm.execute`. Isso diminui as idas e voltas entre a aplicação e o banco de dados, o que torna a inserção de grandes volumes de dados muito mais rápida e alivia a carga do servidor de banco de dados.

## Inserção em massa em uma entidade {#bulk-insert-into-one-entity}

Insere uma lista de categorias.

**Lambda:**

```typescript
Categories.bulkInsert()
```

**Resultado SQL:**

```sql
INSERT INTO Categories(CategoryName,Description) VALUES ?
```

## Inserção em massa com uma entidade relacionada {#bulk-insert-with-a-related-entity}

Insere uma lista de pedidos, cada um com seus detalhes.

**Lambda:**

```typescript
Orders.bulkInsert().include(p => p.details)
```

**Resultado SQL:**

```sql
-- the orders
INSERT INTO Orders(CustomerID,EmployeeID,OrderDate,RequiredDate,ShippedDate,ShipVia,Freight,ShipName,ShipAddress,ShipCity,ShipRegion,ShipPostalCode,ShipCountry) VALUES ?

-- the details of all the orders
INSERT INTO `Order Details`(OrderID,ProductID,UnitPrice,Quantity,Discount) VALUES ?
```

## Exemplo de código {#code-example}

Insere duas categorias e imprime os ids dos registros inseridos.

```typescript
import { orm } from '@lambdaorm/lib'
import { Categories } from './domain/model' // model generated by `lambdaorm build`

(async () => {
	try {
		await orm.init('./lambdaORM.yaml')
		const categories = [
			{ name: 'Beverages4', description: 'Soft drinks, coffees, teas, beers, and ales' },
			{ name: 'Condiments4', description: 'Sweet and savory sauces, relishes, spreads, and seasonings' }
		]
		const query = () => Categories.bulkInsert()
		// returns the ids of the records inserted
		const result = await orm.execute(query, categories)
		console.log(JSON.stringify(result, null, 2))
	} catch (error: any) {
		console.error(error.stack)
	} finally {
		// releases the connections
		await orm.end()
	}
})()
```
