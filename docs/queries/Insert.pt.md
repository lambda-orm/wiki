# Insert {#insert}

Esta página mostra como inserir registros: com todas as propriedades da entidade ou apenas algumas, junto com entidades relacionadas (`include`), e como inserir ou atualizar em um único passo (`upsert`). Para inserir muitos registros de uma só vez, veja [Inserção em massa](BulkInsert.md). O SQL mostrado é o gerado para MySQL, salvo indicação em contrário.

Uma consulta se baseia tanto na expressão quanto no esquema. Se as propriedades a inserir não forem especificadas, todas as propriedades da entidade são inseridas. A forma como cada propriedade é armazenada em cada fonte (nomes de tabelas e colunas) é resolvida pelo mapeamento dessa fonte no esquema.

## Inserir todas as propriedades {#insert-all-the-properties}

Quando as propriedades não são especificadas, os dados passados devem ser um objeto com as propriedades da entidade.

**Lambda:**

```typescript
Categories.insert()
```

**Resultado SQL:**

```sql
INSERT INTO Categories(CategoryName,Description) VALUES(?,?)
```

A chave primária `id` não é inserida porque é autoincremental: o banco de dados a gera.

## Inserir algumas propriedades {#insert-some-properties}

Apenas as propriedades especificadas são inseridas. Aqui, `name` é uma variável dos dados passados para a consulta.

**Lambda:**

```typescript
Categories.insert({ name: name })
```

**Resultado SQL:**

```sql
INSERT INTO Categories(CategoryName) VALUES(?)
```

## Inserir com include {#insert-with-include}

Para inserir um objeto junto com seus objetos relacionados, inclua a relação. Este exemplo insere um pedido e seus detalhes; a chave do novo pedido é atribuída a cada detalhe.

**Lambda:**

```typescript
Orders.insert().include(p => p.details)
```

**Resultado SQL:**

```sql
-- the order
INSERT INTO Orders(CustomerID,EmployeeID,OrderDate,RequiredDate,ShippedDate,ShipVia,Freight,ShipName,ShipAddress,ShipCity,ShipRegion,ShipPostalCode,ShipCountry)
VALUES(?,?,?,?,?,?,?,?,?,?,?,?,?)

-- each detail of the order
INSERT INTO `Order Details`(OrderID,ProductID,UnitPrice,Quantity,Discount)
VALUES(?,?,?,?,?)
```

## Upsert {#upsert}

`upsert()` insere o registro ou, se já existir um registro com a mesma chave primária, o atualiza. Ele é escrito como um insert: `upsert()` com todas as propriedades, ou com as propriedades especificadas. A entidade precisa de uma chave primária, e os dados devem incluí-la (por isso uma chave autoincremental tem pouca utilidade aqui).

**Lambda:**

```typescript
// inserts the country, or updates it when one with the same iso3 exists
Countries.upsert()
```

```typescript
await orm.execute('Countries.upsert()', { iso3: 'ARG', name: 'Argentine' }) // inserted
await orm.execute('Countries.upsert()', { iso3: 'ARG', name: 'Argentina' }) // updated: the same row
```

**Resultado SQL:**

```sql
-- MySQL / MariaDB
INSERT INTO Countries(iso3,name) VALUES(?,?) ON DUPLICATE KEY UPDATE name = VALUES(name)

-- PostgreSQL
INSERT INTO Countries(iso3,name) VALUES($1,$2)
ON CONFLICT (iso3) DO UPDATE SET name = EXCLUDED.name

-- SQL Server
MERGE INTO Countries WITH (HOLDLOCK) AS t
USING (SELECT 1 AS x) AS s
ON t.iso3 = @iso3
WHEN MATCHED THEN UPDATE SET name = @name
WHEN NOT MATCHED THEN INSERT (iso3,name) VALUES (@iso3,@name);

-- Oracle
MERGE INTO Countries t
USING (SELECT 1 FROM DUAL) s
ON (t.iso3 = :iso3)
WHEN MATCHED THEN UPDATE SET name = :name
WHEN NOT MATCHED THEN INSERT (iso3,name) VALUES (:iso3,:name)

-- SQLite
INSERT INTO Countries(iso3,name) VALUES(?,?) ON CONFLICT DO UPDATE SET name = excluded.name
```

O upsert é suportado em PostgreSQL, MySQL, MariaDB, SQL Server e Oracle (estes dois com `MERGE`, a partir de `@lambdaorm/lib` 3.5.0) e SQLite (a partir da 3.15.0). No SQLite, `ON CONFLICT` sem colunas se aplica a um conflito na chave primária ou em qualquer chave única.

!!! warning "Aviso"
    No MongoDB, o upsert ainda não é suportado: falha com o erro `upsert is not supported on MongoDB yet`.

Quando a chave é gerada (autoincremental) e não é enviada, o upsert insere. No SQL Server a coluna identity nunca é inserida (o banco de dados a gera) e `OUTPUT INSERTED` a retorna; o `MERGE` do Oracle não pode retornar valores, por isso retorna a chave que foi enviada.

O upsert também é o que um [update com include](Update.md#update-an-aggregate-composite-relation) de uma relação composta usa para salvar os filhos.

## Exemplo de código {#code-example}

Insere um pedido com dois detalhes e imprime o id do novo pedido.

```typescript
import { orm } from '@lambdaorm/lib'
import { Orders } from './domain/model' // model generated by `lambdaorm build`

(async () => {
	try {
		await orm.init('./lambdaORM.yaml')
		const order = {
			customerId: 'VINET',
			employeeId: 5,
			orderDate: '1996-07-03T22:00:00.000Z',
			requiredDate: '1996-07-31T22:00:00.000Z',
			shippedDate: '1996-07-15T22:00:00.000Z',
			shipViaId: 3,
			freight: 32.38,
			name: 'Vins et alcools Chevalier',
			address: '59 rue de l-Abbaye',
			city: 'Reims',
			postalCode: '51100',
			country: 'France',
			// orderId is assigned from the new order
			details: [
				{ productId: 11, unitPrice: 14, quantity: 12, discount: 10 },
				{ productId: 42, unitPrice: 9.8, quantity: 10, discount: 10 }
			]
		}
		const query = () => Orders.insert().include(p => p.details)
		// returns the id of the order created
		const result = await orm.execute(query, order)
		console.log(JSON.stringify(result))
	} catch (error: any) {
		console.error(error.stack)
	} finally {
		// releases the connections
		await orm.end()
	}
})()
```
