## What this repo is

Documentation wiki for **λORM** (LambdaORM), a distributed TypeScript/Node.js ORM. The site is built with [MkDocs](https://www.mkdocs.org/) using the Read the Docs theme.

- `docs/` — Markdown source files (edit these)
- `wiki/` — pre-built HTML output committed to the repo (generated by `mkdocs build`)
- `mkdocs.yml` — site configuration and navigation

## Commands

```bash
# Preview locally (live reload at http://127.0.0.1:8000)
mkdocs serve

# Build static site into wiki/
mkdocs build

# Deploy to GitHub Pages (creates/updates gh-pages branch)
mkdocs gh-deploy
```

**Requirements:** Python 3.12+, MkDocs installed via pipx:
```bash
pipx install mkdocs
pipx inject mkdocs mkdocs-material
```

## Key workflow

1. Edit Markdown in `docs/`.
2. Run `mkdocs build` to regenerate `wiki/`.
3. Commit both `docs/` and `wiki/` changes — CI publishes the pre-built `wiki/` directory directly to GitHub Pages on push to `main` (it does **not** run `mkdocs build` in CI).

## Commit conventions

Commits follow [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) — this is used to auto-generate changelogs. Branch names follow Git Flow: `feature/<name>`, `bugfix/<name>`, `release/<name>`, `hotfix/<name>`.

## Navigation

The site navigation is defined in `mkdocs.yml` under `nav:`. When adding a new doc page, register it there. Pages are organized into sections: Queries, Schema, Usage, Api, Cli, Labs.
