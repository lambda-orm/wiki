Funcionalidades

Uma visão geral do que o λORM oferece, com links para as páginas que descrevem cada funcionalidade.

Mecanismos de banco de dados

  • MySQL, MariaDB, PostgreSQL, SQL Server, Oracle, MongoDB e SQLite (SQLjs).
  • Uma única consulta pode envolver vários bancos de dados, inclusive de mecanismos diferentes.
  • Mecanismos de banco de dados: as diferenças entre os mecanismos (tipos, strings vazias, upsert, …).

Linguagem de consulta

  • Linguagem de consulta baseada em expressões lambda de JavaScript.
  • As consultas podem ser escritas como código JavaScript/TypeScript ou como string.
  • Cláusulas select, insert, bulk insert, update e delete.
  • Joins e agrupamentos implícitos.
  • Carregamento antecipado (eager loading) de relações com include, inclusive entre bancos de dados.
  • Operadores e funções.
  • Metadados da consulta: os parâmetros, o modelo, as restrições e o plano de execução de uma consulta.

Uso

  • Repositórios e repositórios personalizados.
  • Transações e transações distribuídas, entre fontes e stages.
  • Scripts: um caso de uso inteiro (variáveis, condições, laços e várias consultas) em uma só transação, também pelo Data Gateway.
  • Exemplos de uso: uma única fonte, várias fontes, CQRS e o cliente Node.js.

Esquema

  • Configuração do esquema que desacopla o modelo de domínio da infraestrutura.
  • Configuração em JSON ou YAML.
  • Mapeamentos entre o domínio e a infraestrutura.
  • Herança de entidades (extends).
  • Variáveis de ambiente.
  • Índices, chaves únicas e restrições.
  • Condições e ações baseadas no mecanismo de expressões 3xpr (expressões).
  • Stages: vários cenários de infraestrutura para o mesmo domínio.
  • Sincronização entre o esquema e os bancos de dados: push, pull, fetch, introspect e incorporate.
  • Listeners e subscribers: aguardados e executados na transação da sentença que os dispara.

Desempenho

  • Bulk insert.
  • Consultas de alto desempenho.
  • Pool de conexões.

Ferramentas e clientes

  • Suporte a TypeScript e JavaScript.
  • CLI (npm i -g @lambdaorm/cli, comando lambdaorm).
  • Data Gateway (imagem Docker flaviorita/data-gateway):
    • uma API REST, MCP para agentes de IA e uma API WebSocket, com vários esquemas por instância;
    • credenciais com permissões, auditoria das escritas, métricas e health checks;
    • uma UI web: explorador, formulários de entidades, consultas salvas e diagramas do domínio.
  • Clientes:
    • cliente Node.js (@lambdaorm/client, REST ou WebSocket);
    • outras linguagens: gere um cliente a partir do documento OpenAPI 3 do Data Gateway.
