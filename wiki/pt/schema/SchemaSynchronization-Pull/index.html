    Pull¶

    Esta página explica o pull, que atualiza o arquivo do esquema com a estrutura das fontes (bancos de dados) de um stage: o que ele mantém, o comando da CLI lambdaorm pull e o método orm.stage.pull().

    O que o pull mantém¶

    O pull lê as tabelas e colunas dos bancos de dados e as mescla no esquema: novas tabelas se tornam entidades, novas colunas se tornam propriedades e os mapeamentos são atualizados. O pull não altera os bancos de dados. Por padrão, ele também remove do esquema as entidades, propriedades e relações que não estão mais no banco de dados (orm.stage.pull({ stage, removeEntities: false, removeProperties: false, removeRelations: false }) as mantém). Ele pode ser executado sobre um esquema existente: o que foi escrito à mão é mantido, por exemplo

    • nomes de relações escolhidos à mão e relações weak entre fontes (que não têm chave estrangeira no banco de dados),
    • application.listeners,
    • infrastructure.stages.

    Colunas nomeadas com palavras reservadas (por exemplo order) são suportadas.

    CLI¶

    O comando pull atualiza o arquivo do esquema (lambdaORM.yaml neste exemplo) com a estrutura dos bancos de dados do stage:

    lambdaorm pull
    Opção Descrição
    -w, --workspace Pasta do projeto (padrão: a pasta atual).
    -s, --stage Nome do stage (padrão: o primeiro stage).
    -e, --envfile Arquivo de variáveis de ambiente a ser lido.

    O pull também grava, na pasta orm_state, o modelo do stage e o DDL da estrutura obtida, em uma pasta por fonte. O DDL é um registro: ele não é executado.

    Arquivos criados:

    ├── orm_state
│   ├── default-model.json
│   └── default
│       └── V240501212640__pull.sql

    Node¶

    orm.stage.pull() atualiza o arquivo do esquema com a estrutura dos bancos de dados do stage:

    import { Orm } from '@lambdaorm/lib'
(async () => {
    const orm = new Orm()
    try {
        await orm.init('./lambdaORM.yaml')
        await orm.stage.pull({ stage: 'default' })
    } catch (e) {
        console.log(e)
    } finally {
        await orm.end()
    }
})()
