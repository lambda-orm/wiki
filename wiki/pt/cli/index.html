λORM CLI

A λORM CLI (@lambdaorm/cli) é uma aplicação de linha de comando para usar o λORM: cria projetos, sincroniza os bancos de dados com o esquema, importa e exporta dados e executa consultas e scripts. Seus comandos são executados localmente com um workspace (-w), e a maioria deles também pode ser executada em um Data Gateway (-u <url>).

Instalação

Instale o pacote globalmente; ele adiciona o comando lambdaorm:

npm i -g @lambdaorm/cli
lambdaorm --version

Requer Node.js 20 ou posterior. A imagem Docker do Data Gateway (flaviorita/data-gateway) já inclui a CLI.

Nota

O pacote sem escopo lambdaorm-cli é o antigo e não é mais mantido.

Comandos

Comando Descrição
version Imprime a versão da CLI e a versão de @lambdaorm/lib que o projeto usa.
init Gera a estrutura de um projeto λORM.
build Gera o modelo e os repositórios para a linguagem.
schema Retorna informações sobre o esquema.
push Sincroniza os bancos de dados com o modelo (-o escreve os scripts em vez disso).
pull Atualiza o esquema com a estrutura dos bancos de dados de um stage.
fetch Mostra as diferenças entre os bancos de dados e o modelo; termina com código 1 quando há alguma.
introspect Lê e analisa um arquivo de dados e atualiza o esquema.
incorporate Atualiza o esquema a partir de um arquivo de dados, envia as alterações aos bancos de dados e importa os dados.
drop Remove todos os objetos de banco de dados, mas não o próprio banco de dados.
import Importa dados de um arquivo para os bancos de dados.
export Exporta dados dos bancos de dados.
execute Executa uma consulta.
script Executa um script: várias consultas em uma transação.
plan Retorna o plano de execução de uma consulta.
metadata Retorna os metadados de uma consulta.
parameters Retorna os parâmetros de uma consulta.
model Retorna o modelo do resultado de uma consulta.
constraints Retorna as restrições (constraints) de uma consulta.

lambdaorm <command> -h lista as opções de um comando; lambdaorm -h lista os comandos.

O comando sync não existe mais: foi substituído por push.

Opções comuns

Opção Abreviação Descrição
workspace -w Caminho do projeto (a pasta com lambdaORM.yaml). Padrão: o diretório atual.
stage -s Nome do stage. Padrão: o primeiro stage do esquema.
envfile -e Lê um arquivo de variáveis de ambiente (por exemplo, as strings de conexão).
output -o Formato de saída do resultado: json, beautiful, light ou yaml.
url -u URL do esquema em um Data Gateway, para executar o comando nele em vez de localmente.

A página de cada comando lista as opções que esse comando aceita.

Código de saída e Data Gateway

Todo comando termina com código 1 quando falha (a partir de @lambdaorm/cli 1.6.3).

Os comandos são executados em um Data Gateway com -u e a URL do esquema, por exemplo http://gateway:8080/iot/v1. Quando a variável de ambiente SERVICE_TOKEN está definida, ela é enviada como Authorization: Bearer <token> (para um gateway com autenticação bearer). Veja também Clientes.
