Expressões lambda

Esta página resume os elementos de uma consulta λORM: os métodos encadeados sobre uma entidade e os operadores e funções que podem ser usados dentro das lambdas. Use-a como referência rápida; cada método tem um link para a página com seus exemplos.

As consultas são expressões lambda escritas na própria linguagem de programação. Elas se referem às entidades e propriedades do domínio, por isso são independentes da linguagem do banco de dados e da forma como os dados são armazenados.

Exemplo

A consulta a seguir lê os produtos cujo nome começa com "A", com o nome da sua categoria, ordenados por categoria (ascendente) e produto (descendente), e retorna a primeira página de 10 registros:

Products
    .filter(p => upper(substr(p.name, 1, 1)) == "A")
    .map(p => ({ category: p.category.name, product: p.name }))
    .sort(p => [p.category, desc(p.product)])
    .page(1, 10)

No Oracle, o λORM a traduz para:

SELECT c.CategoryName AS "category", p.ProductName AS "product"
FROM Products p
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
WHERE UPPER(SUBSTR(p.ProductName,1,1)) = 'A'
ORDER BY "category" asc, "product" desc
OFFSET 0 ROWS FETCH NEXT 10 ROWS ONLY

A mesma consulta é executada em qualquer outro mecanismo de banco de dados: no MySQL, por exemplo, a paginação se torna LIMIT 0,10.

Vantagens

  • As consultas são escritas na mesma linguagem de programação da aplicação.
  • Não há uma nova linguagem para aprender.
  • As expressões são fáceis de escrever e de ler.
  • O IntelliSense da IDE ajuda a escrever as expressões.
  • Os erros de sintaxe são detectados enquanto você escreve.

Métodos de consulta

Método Descrição Equivalente em SQL Exemplos
filter Filtra os registros. WHERE Select
having Filtra os grupos. HAVING Agrupamento
map Especifica as propriedades a retornar. SELECT Select
distinct Especifica as propriedades a retornar, removendo os registros duplicados. SELECT DISTINCT Select
first Retorna o primeiro registro. SELECT + ORDER BY + LIMIT Select
last Retorna o último registro. SELECT + ORDER BY DESC + LIMIT Select
sort Especifica a ordem dos registros. ORDER BY Select
page Pagina os registros. LIMIT / OFFSET (depende do dialeto) Select
include Carrega os registros de entidades relacionadas. Include
insert Insere um registro. INSERT Insert
upsert Insere um registro, ou o atualiza se já existir um com a mesma chave primária. INSERT … ON CONFLICT / MERGE Insert
bulkInsert Insere muitos registros de uma só vez. INSERT Inserção em massa
update Atualiza registros; sempre tem um filtro. UPDATE com WHERE Update
updateAll Atualiza todos os registros de uma entidade. UPDATE sem WHERE Update
delete Exclui registros; sempre tem um filtro. DELETE com WHERE Delete
deleteAll Exclui todos os registros de uma entidade. DELETE sem WHERE Delete
  • Não há método para joins: um INNER JOIN é deduzido quando a consulta navega por uma relação, como em p.category.name (veja Join).
  • Não há método para GROUP BY: ele é deduzido quando uma função de agregação é usada (veja Agrupamento).
