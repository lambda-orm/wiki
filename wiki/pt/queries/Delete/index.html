Delete

Esta página mostra como excluir registros: com um filtro, pela chave primária, todos os registros de uma entidade e junto com entidades relacionadas. O SQL mostrado é o gerado para MySQL.

delete retorna o número de linhas afetadas: 0 significa que nenhuma linha atendeu ao filtro.

const count = await orm.execute('Categories.delete().filter(p => p.id == id)', { id: 9 }) // 1

Excluir com um filtro

Exclui os detalhes de um pedido.

Lambda:

Orders.details.delete().filter(p => p.orderId === id)

Resultado SQL:

DELETE o FROM `Order Details` AS o WHERE o.OrderID = ?

Excluir pela chave primária

Quando delete() não tem filtro, ele filtra pela chave primária, cujo valor é obtido dos dados passados. A chave primária dos detalhes do pedido é formada por orderId e productId:

Lambda:

Orders.details.delete()

Resultado SQL:

DELETE o FROM `Order Details` AS o WHERE (o.OrderID = ? AND o.ProductID = ?)

Excluir todos os registros

Para excluir todos os registros de uma entidade, use deleteAll em vez de delete. Isso evita excluir todos os registros por engano.

Lambda:

Orders.details.deleteAll()

Resultado SQL:

DELETE FROM `Order Details`

Excluir uma entidade e suas entidades relacionadas

Exclui um pedido e seus detalhes. O pedido é filtrado pela sua chave primária, e cada detalhe enviado, pela sua própria chave primária. Os detalhes são excluídos primeiro e, depois, o pedido.

Lambda:

Orders.delete().include(p => p.details)

Resultado SQL:

-- the order
DELETE o FROM Orders AS o WHERE o.OrderID = ?

-- each detail sent
DELETE o1 FROM `Order Details` AS o1 WHERE (o1.OrderID = ? AND o1.ProductID = ?)

Exemplo de código

Exclui um pedido com seus detalhes e imprime o número de pedidos excluídos.

import { orm } from '@lambdaorm/lib'
import { Orders } from './domain/model' // model generated by `lambdaorm build`

(async () => {
    try {
        await orm.init('./lambdaORM.yaml')
        const order = {
            id: 1,
            customerId: 'ALFKI',
            employeeId: 6,
            orderDate: '1997-08-24T22:00:00.000Z',
            requiredDate: '1997-09-21T22:00:00.000Z',
            shippedDate: '1997-09-01T22:00:00.000Z',
            shipViaId: 1,
            freight: '29.4600',
            name: 'Alfreds Futterkiste',
            address: 'Obere Str. 57',
            city: 'Berlin',
            region: null,
            postalCode: '12209',
            country: 'Germany',
            details: [
                {
                    orderId: 1,
                    productId: 28,
                    unitPrice: '45.6000',
                    quantity: '15.0000',
                    discount: '0.0000'
                },
                {
                    orderId: 1,
                    productId: 39,
                    unitPrice: '18.0000',
                    quantity: '21.0000',
                    discount: '0.0000'
                }
            ]
        }
        const query = () => Orders.delete().include(p => p.details)
        // returns the number of orders deleted
        const count = await orm.execute(query, order)
        console.log(count)
    } catch (error: any) {
        console.error(error.stack)
    } finally {
        // releases the connections
        await orm.end()
    }
})()
