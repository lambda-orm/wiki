    Agrupamento¶

    Esta página mostra como agrupar registros e calcular agregados (somas, contagens, máximos…), e como filtrar os grupos com having. O SQL mostrado é o gerado para MySQL.

    O agrupamento não é declarado: o λORM o deduz quando a consulta usa uma função de agregação. Os registros são agrupados pelas propriedades retornadas que não estão dentro de uma função de agregação.

    Funções de agregação¶

    Função Descrição
    avg Calcula a média dos valores de um grupo.
    count Conta os registros de um grupo.
    first Retorna o primeiro valor de um grupo.
    last Retorna o último valor de um grupo.
    max Calcula o máximo.
    min Calcula o mínimo.
    sum Calcula a soma.

    Soma com filtro e ordenação¶

    Lê, para os pedidos de um cliente, a data do pedido e o total (soma de quantidade × preço unitário), ordenados pelo total em ordem decrescente. Os registros são agrupados por order, a única propriedade retornada que não é um agregado.

    Lambda:

    Orders.details
    .filter(p => p.order.customer.name == customerName)
    .map(p => ({ order: p.order.orderDate, total: sum(p.quantity * p.unitPrice) }))
    .sort(p => desc(p.total))

    Resultado SQL:

    SELECT o1.OrderDate AS `order`, SUM((o.Quantity * o.UnitPrice)) AS total
FROM `Order Details` o
INNER JOIN Orders o1 ON o1.OrderID = o.OrderID
INNER JOIN Customers c ON c.CustomerID = o1.CustomerID
WHERE c.CompanyName = ?
GROUP BY o1.OrderDate
ORDER BY total desc

    Agrupamento e having¶

    Lê o preço mais alto de cada categoria, considerando os produtos com preço maior que 5 cujo fornecedor é de um determinado país, ou com menos de 3 unidades em estoque. Só são retornadas as categorias cujo preço mais alto é maior que 50, ordenadas por esse preço em ordem decrescente.

    filter é aplicado aos registros antes do agrupamento (WHERE); having é aplicado aos grupos (HAVING).

    Lambda:

    Products
    .filter(p => (p.price > 5 && p.supplier.country == country) || (p.inStock < 3))
    .having(p => max(p.price) > 50)
    .map(p => ({ category: p.category.name, largestPrice: max(p.price) }))
    .sort(p => desc(p.largestPrice))

    Resultado SQL:

    SELECT c.CategoryName AS category, MAX(p.UnitPrice) AS largestPrice
FROM Products p
INNER JOIN Suppliers s ON s.SupplierID = p.SupplierID
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
WHERE ((p.UnitPrice > 5 AND s.Country = ?) OR p.UnitsInStock < 3)
GROUP BY c.CategoryName
HAVING MAX(p.UnitPrice) > 50
ORDER BY largestPrice desc

    Exemplo de código¶

    import { orm } from '@lambdaorm/lib'
import { Products } from './domain/model' // model generated by `lambdaorm build`

(async () => {
    try {
        await orm.init('./lambdaORM.yaml')
        // highest price per category, for the categories whose highest price is greater than 50
        const query = (country: string) => Products
            .filter(p => (p.price > 5 && p.supplier.country == country) || (p.inStock < 3))
            .having(p => max(p.price) > 50)
            .map(p => ({ category: p.category.name, largestPrice: max(p.price) }))
            .sort(p => desc(p.largestPrice))
        const result = await orm.execute(query, { country: 'USA' })
        console.log(JSON.stringify(result, null, 2))
    } catch (error: any) {
        console.error(error.stack)
    } finally {
        // releases the connections
        await orm.end()
    }
})()
