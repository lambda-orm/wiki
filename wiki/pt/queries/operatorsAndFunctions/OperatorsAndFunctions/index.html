Operadores e funções

As consultas λORM são expressões lambda, e dentro delas é possível usar os operadores e funções listados nesta referência. O λORM traduz cada um para a linguagem do mecanismo de banco de dados da fonte de dados: SQL para MySQL, MariaDB, PostgreSQL, SQL Server, Oracle e SQLite, e pipelines de agregação para MongoDB. Veja Linguagem de consulta para uma introdução às consultas.

Cada página descreve os operadores e funções de uma categoria, com sua assinatura, uma consulta de exemplo, seu resultado e o SQL gerado para ela. Nem toda função pode ser traduzida para todos os mecanismos de banco de dados; cada página termina com uma seção Suporte nos bancos de dados que lista as diferenças.
