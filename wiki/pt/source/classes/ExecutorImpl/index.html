transaction()

transaction(options, callback): Promise\<void>

Defined in: packages/lib/src/lib/execution/application/services/executor.ts:110

Create a transaction: commit when the callback ends, rollback (and rethrow its error) when it fails. Inside a transaction in course, the callback joins it: the outer transaction commits or rolls back. A transaction can run on several stages (an execution with another stage joins it too); all of them share the connections, one per source, and commit or roll back together.
