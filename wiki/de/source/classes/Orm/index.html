    executeScript()¶

    executeScript(script, data?, options?): Promise\<any>

    Defined in: packages/lib/src/lib/orm/infrastructure/orm.ts:253

    Evaluates a 3xpr script whose orm.execute calls all run in one transaction (also across sources): commit when it ends, rollback and rethrow when anything fails.

    Parameters¶

    script¶

    string

    statements calling orm.execute(query, data, options), with variables, if, for, throw, return

    data?¶

    any = {}

    variables of the script (the script works on a copy)

    options?¶

    ScriptOptions

    stage (…) of the script's transaction, shared by every orm.execute without its own; timeout (ms: when it passes the loops stop, the transaction rolls back and the script rejects) and maxIterations (loop iterations of the script, all loops together)

    Returns¶

    Promise\<any>

    the value of the last statement (or of return)

    Implementation of¶

    IOrm.executeScript
