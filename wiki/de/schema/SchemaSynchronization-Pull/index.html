Pull

Diese Seite erklärt pull, das die Schema-Datei mit der Struktur der Quellen (Datenbanken) eines Stages aktualisiert: was erhalten bleibt, den CLI-Befehl lambdaorm pull und die Methode orm.stage.pull().

Was pull erhält

Pull liest die Tabellen und Spalten der Datenbanken und führt sie im Schema zusammen: Neue Tabellen werden zu Entitäten, neue Spalten zu Eigenschaften, und die Mappings werden aktualisiert. Pull ändert die Datenbanken nicht. Standardmäßig entfernt es außerdem die Entitäten, Eigenschaften und Beziehungen aus dem Schema, die nicht mehr in der Datenbank vorhanden sind (orm.stage.pull({ stage, removeEntities: false, removeProperties: false, removeRelations: false }) behält sie bei). Es kann auf ein bestehendes Schema angewendet werden: Was von Hand geschrieben wurde, bleibt erhalten, zum Beispiel

  • von Hand gewählte Beziehungsnamen und weak-Beziehungen zwischen Quellen (die in der Datenbank keinen Fremdschlüssel haben),
  • application.listeners,
  • infrastructure.stages.

Spalten, deren Namen reservierte Wörter sind (zum Beispiel order), werden unterstützt.

CLI

Der Befehl pull aktualisiert die Schema-Datei (in diesem Beispiel lambdaORM.yaml) mit der Struktur der Datenbanken des Stages:

lambdaorm pull
Option Beschreibung
-w, --workspace Ordner des Projekts (Standard: der aktuelle Ordner).
-s, --stage Name des Stages (Standard: der erste Stage).
-e, --envfile Zu lesende Datei mit Umgebungsvariablen.

Pull schreibt außerdem in den Ordner orm_state das Modell des Stages und die DDL der übernommenen Struktur, in einem Ordner pro Quelle. Die DDL dient als Protokoll: Sie wird nicht ausgeführt.

Erstellte Dateien:

├── orm_state
│   ├── default-model.json
│   └── default
│       └── V240501212640__pull.sql

Node

orm.stage.pull() aktualisiert die Schema-Datei mit der Struktur der Datenbanken des Stages:

import { Orm } from '@lambdaorm/lib'
(async () => {
    const orm = new Orm()
    try {
        await orm.init('./lambdaORM.yaml')
        await orm.stage.pull({ stage: 'default' })
    } catch (e) {
        console.log(e)
    } finally {
        await orm.end()
    }
})()
