    Lambda-Ausdrücke¶

    Diese Seite fasst die Bausteine einer λORM-Abfrage zusammen: die Methoden, die Sie an einer Entität verketten, sowie die Operatoren und Funktionen, die Sie innerhalb der Lambdas verwenden können. Nutzen Sie sie als Kurzreferenz; jede Methode verweist auf die Seite mit ihren Beispielen.

    Abfragen sind Lambda-Ausdrücke, die in der Programmiersprache selbst geschrieben werden. Sie beziehen sich auf die Entitäten und Eigenschaften der Domäne und sind daher unabhängig von der Sprache der Datenbank und davon, wie die Daten gespeichert sind.

    Beispiel¶

    Die folgende Abfrage liest die Produkte, deren Name mit „A“ beginnt, zusammen mit dem Namen ihrer Kategorie, sortiert nach Kategorie (aufsteigend) und Produkt (absteigend), und gibt die erste Seite mit 10 Datensätzen zurück:

    Products
    .filter(p => upper(substr(p.name, 1, 1)) == "A")
    .map(p => ({ category: p.category.name, product: p.name }))
    .sort(p => [p.category, desc(p.product)])
    .page(1, 10)

    Auf Oracle übersetzt λORM sie in:

    SELECT c.CategoryName AS "category", p.ProductName AS "product"
FROM Products p
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
WHERE UPPER(SUBSTR(p.ProductName,1,1)) = 'A'
ORDER BY "category" asc, "product" desc
OFFSET 0 ROWS FETCH NEXT 10 ROWS ONLY

    Dieselbe Abfrage läuft auf jeder anderen Datenbank-Engine: Auf MySQL wird die Paginierung beispielsweise zu LIMIT 0,10.

    Vorteile¶

    • Abfragen werden in derselben Programmiersprache wie die Anwendung geschrieben.
    • Es muss keine neue Sprache gelernt werden.
    • Ausdrücke sind leicht zu schreiben und zu lesen.
    • IntelliSense der IDE hilft beim Schreiben der Ausdrücke.
    • Syntaxfehler werden bereits beim Schreiben erkannt.

    Abfragemethoden¶

    Methode Beschreibung SQL-Entsprechung Beispiele
    filter Filtert die Datensätze. WHERE Select
    having Filtert die Gruppen. HAVING Grouping
    map Legt die zurückzugebenden Eigenschaften fest. SELECT Select
    distinct Legt die zurückzugebenden Eigenschaften fest und entfernt doppelte Datensätze. SELECT DISTINCT Select
    first Gibt den ersten Datensatz zurück. SELECT + ORDER BY + LIMIT Select
    last Gibt den letzten Datensatz zurück. SELECT + ORDER BY DESC + LIMIT Select
    sort Legt die Reihenfolge der Datensätze fest. ORDER BY Select
    page Paginiert die Datensätze. LIMIT / OFFSET (abhängig vom Dialekt) Select
    include Lädt die Datensätze verbundener Entitäten. Include
    insert Fügt einen Datensatz ein. INSERT Insert
    upsert Fügt einen Datensatz ein oder aktualisiert ihn, falls einer mit demselben Primärschlüssel existiert. INSERT … ON CONFLICT / MERGE Insert
    bulkInsert Fügt viele Datensätze auf einmal ein. INSERT Bulk Insert
    update Aktualisiert Datensätze; hat immer einen Filter. UPDATE mit WHERE Update
    updateAll Aktualisiert alle Datensätze einer Entität. UPDATE ohne WHERE Update
    delete Löscht Datensätze; hat immer einen Filter. DELETE mit WHERE Delete
    deleteAll Löscht alle Datensätze einer Entität. DELETE ohne WHERE Delete
    • Es gibt keine Methode für Joins: Ein INNER JOIN wird abgeleitet, wenn die Abfrage eine Beziehung durchläuft, wie in p.category.name (siehe Join).
    • Es gibt keine Methode für GROUP BY: Es wird abgeleitet, wenn eine Aggregatfunktion verwendet wird (siehe Grouping).

    Operatoren¶

    Die Operatoren sind dieselben wie in JavaScript.

    Kategorie Operatoren Weitere Informationen
    Arithmetisch -, +, *, /, **, //, % Numeric
    Bitweise ~, &, \|, ^, <<, >> Bitwise
    Vergleich ==, ===, !=, !==, >, <, >=, <= Comparison
    Logisch !, &&, \|\| Logical
    Array []

    Kategorie Funktionen Weitere Informationen

    Datum/Uhrzeit curTime, today, now, time, date, dateTime, year, month, day, weekday, hours… Datetime

    Allgemein as, distinct
    Sortierung asc, desc Sort

    Gruppe avg, count, first, last, max, min, sum Group
