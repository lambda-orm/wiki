Select

Diese Seite zeigt, wie Sie Datensätze lesen: alle Eigenschaften einer Entität oder nur einige davon, den ersten oder letzten Datensatz, eindeutige Werte und Paginierung. Das gezeigte SQL ist das für MySQL erzeugte.

Jede Abfrage beruht auf dem Schema, aus dem λORM die Eigenschaften jeder Entität, ihren Primärschlüssel, ihre Indizes, Beziehungen und Constraints kennt. Deshalb müssen Sie die Eigenschaften nicht aufzählen, um alle Eigenschaften einer Entität zu lesen.

Alle Eigenschaften einer Entität

Liest alle Eigenschaften aller Produkte.

Lambda:

Products

SQL-Ergebnis:

SELECT
    p.ProductID AS id,
    p.ProductName AS name,
    p.SupplierID AS supplierId,
    p.CategoryID AS categoryId,
    p.QuantityPerUnit AS quantity,
    p.UnitPrice AS price,
    p.UnitsInStock AS inStock,
    p.UnitsOnOrder AS onOrder,
    p.ReorderLevel AS reorderLevel,
    p.Discontinued AS discontinued
FROM Products p

Eine Eigenschaft

Liest nur den Namen jedes Produkts.

Lambda:

Products.map(p => p.name)

SQL-Ergebnis:

SELECT p.ProductName AS name FROM Products p

Erster Datensatz

Liest das erste Produkt, sortiert nach seinem Primärschlüssel.

Lambda:

Products.first()

SQL-Ergebnis:

SELECT
    p.ProductID AS id,
    p.ProductName AS name,
    p.SupplierID AS supplierId,
    p.CategoryID AS categoryId,
    p.QuantityPerUnit AS quantity,
    p.UnitPrice AS price,
    p.UnitsInStock AS inStock,
    p.UnitsOnOrder AS onOrder,
    p.ReorderLevel AS reorderLevel,
    p.Discontinued AS discontinued
FROM Products p
ORDER BY p.ProductID asc
LIMIT 0,1

first kann, wie map, auch die zurückzugebenden Eigenschaften erhalten: Products.first(p => ({ name: p.name, price: p.price })). In diesem Fall werden die Datensätze nach der ersten zurückgegebenen Eigenschaft sortiert.

Letzter Datensatz

Liest das letzte Produkt, sortiert nach seinem Primärschlüssel.

Lambda:

Products.last()

SQL-Ergebnis:

SELECT
    p.ProductID AS id,
    p.ProductName AS name,
    p.SupplierID AS supplierId,
    p.CategoryID AS categoryId,
    p.QuantityPerUnit AS quantity,
    p.UnitPrice AS price,
    p.UnitsInStock AS inStock,
    p.UnitsOnOrder AS onOrder,
    p.ReorderLevel AS reorderLevel,
    p.Discontinued AS discontinued
FROM Products p
ORDER BY p.ProductID desc
LIMIT 0,1

Distinct

Liest die eindeutigen Kombinationen aus Menge pro Einheit und Kategoriename, sortiert nach Kategorie. Der Kategoriename stammt aus der Beziehung category, daher fügt λORM den Join hinzu (siehe Join).

Lambda:

Products
    .distinct(p => ({ quantity: p.quantity, category: p.category.name }))
    .sort(p => p.category)

SQL-Ergebnis:

SELECT DISTINCT p.QuantityPerUnit AS quantity, c.CategoryName AS category
FROM Products p
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
ORDER BY category asc

Paginierung

Liest Name und Kategorie der Produkte mit einem Preis über 10, sortiert nach Kategorie, und gibt die erste Seite mit 10 Datensätzen zurück.

Lambda:

Products
    .filter(p => p.price > 10)
    .map(p => ({ name: p.name, category: p.category.name }))
    .sort(p => p.category)
    .page(1, 10)

SQL-Ergebnis:

SELECT p.ProductName AS name, c.CategoryName AS category
FROM Products p
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
WHERE p.UnitPrice > 10
ORDER BY category asc
LIMIT 0,10

page(page, records) erhält die Seitennummer (beginnend bei 1) und die Anzahl der Datensätze pro Seite. Wie die Seite ausgedrückt wird, hängt vom Dialekt ab: LIMIT auf MySQL, OFFSET … FETCH NEXT … ROWS ONLY auf Oracle und so weiter.

Verwendung

Dieselbe Abfrage mit dem Mindestpreis als Parameter (minPrice), auf drei Arten ausgeführt.

Node

Mit der Bibliothek @lambdaorm/lib:

import { orm } from '@lambdaorm/lib'
import { Products } from './domain/model' // model generated by `lambdaorm build`

(async () => {
    try {
        await orm.init('./lambdaORM.yaml')
        // products with a price greater than minPrice, with their category, first page of 10
        const query = (minPrice: number) => Products
            .filter(p => p.price > minPrice)
            .map(p => ({ name: p.name, category: p.category.name }))
            .sort(p => p.category)
            .page(1, 10)
        const result = await orm.execute(query, { minPrice: 10 })
        console.log(JSON.stringify(result, null, 2))
    } catch (error: any) {
        console.error(error.stack)
    } finally {
        // releases the connections
        await orm.end()
    }
})()

CLI

Mit der CLI @lambdaorm/cli:

lambdaorm execute -q "Products.filter(p=>p.price>minPrice).map(p=>({name:p.name,category:p.category.name})).sort(p=>p.category).page(1,10)" -d "{\"minPrice\":10}"

Data Gateway

Über die REST API des Data Gateway:

curl -X POST "http://localhost:8080/execute?format=beautiful" -H "X-Api-Key: $KEY" -H "Content-Type: application/json" \
  -d '{"query": "Products.filter(p=>p.price>minPrice).map(p=>({name:p.name,category:p.category.name})).sort(p=>p.category).page(1,10)", "data": {"minPrice": 10}}'
