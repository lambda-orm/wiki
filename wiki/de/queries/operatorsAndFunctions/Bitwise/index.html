Bitweise Operatoren

Bitweise Operatoren arbeiten auf der Binärdarstellung ganzzahliger Werte.

Zu den Beispielen

Die Beispiele laufen gegen die Entität Countries des Beispielschemas für Länder. Jedes zeigt die Abfrage, das Ergebnis, das sie auf der Testdatenbank geliefert hat, und die SQL-Anweisung, die λORM für MySQL erzeugt hat. Andere Datenbank-Engines erhalten ihre eigene Übersetzung; um die für Ihre Datenquelle erzeugte Anweisung zu sehen, verwenden Sie orm.plan.

Ergebnisse auf MySQL

MySQL wertet bitweise Operationen als vorzeichenlose 64-Bit-Ganzzahlen aus. Der Längengrad von Brasilien ist -55, daher sind mehrere der folgenden Ergebnisse sehr große Zahlen.

Übersicht

Operator Beschreibung
~ Bitweises NOT
& Bitweises AND
| Bitweises OR
^ Bitweises XOR (exklusives OR); dies ist keine Potenzierung, verwenden Sie dafür **
<< Linksverschiebung
>> Rechtsverschiebung

Bitweises NOT (~)

Invertiert alle Bits von a. Operanden und Ergebnis sind Zahlen.

Syntax: ~a

Countries.filter(p=> p.iso3=="BRA").first(p=> {result: ~ p.longitude })

Ergebnis: [{"result":54}]

Erzeugtes SQL (MySQL):

SELECT ~ c.longitude AS result
FROM Countries c
WHERE c.iso3 = 'BRA'
ORDER BY result asc
LIMIT 0,1

Bitweises AND (&)

Jedes Bit des Ergebnisses ist 1, wenn die entsprechenden Bits von a und b beide 1 sind. Operanden und Ergebnis sind Zahlen.

Syntax: a & b

Countries.filter(p=> p.iso3=="BRA").first(p=> {result: p.longitude & 1 })

Ergebnis: [{"result":1}]

Erzeugtes SQL (MySQL):

SELECT c.longitude & 1 AS result
FROM Countries c
WHERE c.iso3 = 'BRA'
ORDER BY result asc
LIMIT 0,1

Bitweises OR (|)

Jedes Bit des Ergebnisses ist 1, wenn das entsprechende Bit von a oder von b 1 ist. Operanden und Ergebnis sind Zahlen.

Syntax: a | b

Countries.filter(p=> p.iso3=="BRA").first(p=> {result: p.longitude | 1 })

Ergebnis: [{"result":18446744073709552000}]

Erzeugtes SQL (MySQL):

SELECT c.longitude | 1 AS result
FROM Countries c
WHERE c.iso3 = 'BRA'
ORDER BY result asc
LIMIT 0,1

Bitweises XOR (^)

Jedes Bit des Ergebnisses ist 1, wenn sich die entsprechenden Bits von a und b unterscheiden. Operanden und Ergebnis sind Zahlen.

Syntax: a ^ b

Countries.filter(p=> p.iso3=="BRA").first(p=> {result: p.longitude ^ 1 })

Ergebnis: [{"result":18446744073709552000}]

Erzeugtes SQL (MySQL):

SELECT c.longitude ^ 1 AS result
FROM Countries c
WHERE c.iso3 = 'BRA'
ORDER BY result asc
LIMIT 0,1

Linksverschiebung (<<)

Verschiebt die Bits von a um b Stellen nach links. Operanden und Ergebnis sind Zahlen.

Syntax: a << b

Countries.filter(p=> p.iso3=="BRA").first(p=> {result: p.longitude << 1 })

Ergebnis: [{"result":18446744073709552000}]

Erzeugtes SQL (MySQL):

SELECT c.longitude << 1 AS result
FROM Countries c
WHERE c.iso3 = 'BRA'
ORDER BY result asc
LIMIT 0,1

Rechtsverschiebung (>>)

Verschiebt die Bits von a um b Stellen nach rechts. Operanden und Ergebnis sind Zahlen.

Syntax: a >> b

Countries.filter(p=> p.iso3=="BRA").first(p=> {result: p.longitude >> 1 })

Ergebnis: [{"result":9223372036854776000}]

Erzeugtes SQL (MySQL):

SELECT c.longitude >> 1 AS result
FROM Countries c
WHERE c.iso3 = 'BRA'
ORDER BY result asc
LIMIT 0,1

Datenbankunterstützung

Unterschiede zwischen Datenbank-Engines

  • Oracle: &, | und ^ werden in BITAND, BITOR und BITXOR übersetzt.
  • PostgreSQL: ^ wird in den Operator # (XOR) übersetzt.
  • MongoDB: Bitweise Operatoren können derzeit nicht in MongoDB-Abfragen übersetzt werden.
