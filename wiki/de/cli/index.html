λORM CLI

Die λORM CLI (@lambdaorm/cli) ist eine Kommandozeilenanwendung zur Verwendung von λORM: Sie erstellt Projekte, synchronisiert die Datenbanken mit dem Schema, importiert und exportiert Daten und führt Abfragen und Skripte aus. Ihre Befehle laufen lokal mit einem Workspace (-w), und die meisten von ihnen können auch auf einem Data Gateway ausgeführt werden (-u <url>).

Installation

Installieren Sie das Paket global; es stellt den Befehl lambdaorm bereit:

npm i -g @lambdaorm/cli
lambdaorm --version

Es erfordert Node.js 20 oder höher. Das Docker-Image des Data Gateway (flaviorita/data-gateway) enthält die CLI bereits.

Hinweis

Das Paket lambdaorm-cli ohne Scope ist das alte Paket und wird nicht mehr gepflegt.

Befehle

Befehl Beschreibung
version Gibt die Version der CLI und die vom Projekt verwendete Version von @lambdaorm/lib aus.
init Erzeugt die Struktur eines λORM-Projekts.
build Erzeugt das Modell und die Repositories für die Sprache.
schema Gibt Informationen über das Schema zurück.
push Synchronisiert die Datenbanken mit dem Modell (-o schreibt stattdessen die Skripte).
pull Aktualisiert das Schema mit der Struktur der Datenbanken eines Stages.
fetch Zeigt die Unterschiede zwischen den Datenbanken und dem Modell; endet mit Exit-Code 1, wenn es welche gibt.
introspect Liest und analysiert eine Datendatei und aktualisiert das Schema.
incorporate Aktualisiert das Schema anhand einer Datendatei, überträgt die Änderungen in die Datenbanken und importiert die Daten.
drop Entfernt alle Datenbankobjekte, nicht jedoch die Datenbank selbst.
import Importiert Daten aus einer Datei in die Datenbanken.
export Exportiert Daten aus den Datenbanken.
execute Führt eine Abfrage aus.
script Führt ein Skript aus: mehrere Abfragen in einer Transaktion.
plan Gibt den Ausführungsplan einer Abfrage zurück.
metadata Gibt die Metadaten einer Abfrage zurück.
parameters Gibt die Parameter einer Abfrage zurück.
model Gibt das Modell des Ergebnisses einer Abfrage zurück.
constraints Gibt die Constraints einer Abfrage zurück.

lambdaorm <command> -h listet die Optionen eines Befehls auf; lambdaorm -h listet die Befehle auf.

Den Befehl sync gibt es nicht mehr: Er wurde durch push ersetzt.

Gemeinsame Optionen

Option Kurz Beschreibung
workspace -w Pfad des Projekts (der Ordner mit lambdaORM.yaml). Standard: das aktuelle Verzeichnis.
stage -s Name des Stages. Standard: der erste Stage des Schemas.
envfile -e Liest eine Datei mit Umgebungsvariablen (zum Beispiel die Verbindungszeichenfolgen).
output -o Ausgabeformat des Ergebnisses: json, beautiful, light oder yaml.
url -u URL des Schemas auf einem Data Gateway, um den Befehl dort statt lokal auszuführen.

Jede Befehlsseite listet die Optionen auf, die der jeweilige Befehl akzeptiert.

Exit-Code und Data Gateway

Jeder Befehl endet mit Exit-Code 1, wenn er fehlschlägt (ab @lambdaorm/cli 1.6.3).

Befehle laufen auf einem Data Gateway mit -u und der URL des Schemas, zum Beispiel http://gateway:8080/iot/v1. Ist die Umgebungsvariable SERVICE_TOKEN gesetzt, wird sie als Authorization: Bearer <token> gesendet (für ein Gateway mit Bearer-Authentifizierung). Siehe auch Clients.
