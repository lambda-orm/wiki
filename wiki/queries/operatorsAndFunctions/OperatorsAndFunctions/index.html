Operators and Functions

λORM queries are lambda expressions, and inside them you can use the operators and functions listed in this reference. λORM translates each one into the language of the database engine of the data source: SQL for MySQL, MariaDB, PostgreSQL, SQL Server, Oracle and SQLite, and aggregation pipelines for MongoDB. See Query Language for an introduction to queries.

Each page describes the operators and functions of one category, with their signature, an example query, its result and the SQL generated for it. Not every function can be translated to every engine; each page ends with a Database support section that lists the differences.

Scalar operators and functions

Page Contents
Comparison ==, !=, >, <, >=, <=, between, in, includes
Logical !, &&, ||
Numeric Arithmetic operators and mathematical functions (abs, round, log, sin, ...)
String Text functions (concat, lower, upper, replace, substring, ...)
Date and time Current date, conversions, date parts, intervals and date differences
Nullable nvl, nvl2, isNull, isNotNull
Bitwise ~, &, |, ^, <<, >>

Aggregation and sorting

Page Contents
Group Aggregate functions: count, sum, avg, min, max, first, last
Sort asc and desc, used in sort

Tip

To check how a query is translated for a given data source without running it, use orm.plan.
