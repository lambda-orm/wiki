Pull

Esta página explica pull, que actualiza el archivo del esquema con la estructura de las fuentes (bases de datos) de un stage: qué conserva, el comando de la CLI lambdaorm pull y el método orm.stage.pull().

Qué conserva pull

Pull lee las tablas y columnas de las bases de datos y las fusiona en el esquema: las tablas nuevas pasan a ser entidades, las columnas nuevas pasan a ser propiedades y los mappings se actualizan. Pull no modifica las bases de datos. Por defecto también elimina del esquema las entidades, propiedades y relaciones que ya no están en la base de datos (orm.stage.pull({ stage, removeEntities: false, removeProperties: false, removeRelations: false }) las conserva). Se puede ejecutar sobre un esquema existente: lo que se escribió a mano se conserva, por ejemplo

  • los nombres de relación elegidos a mano y las relaciones weak entre fuentes (que no tienen clave foránea en la base de datos),
  • application.listeners,
  • infrastructure.stages.

Se admiten columnas con nombres que son palabras reservadas (por ejemplo order).

CLI

El comando pull actualiza el archivo del esquema (lambdaORM.yaml en este ejemplo) con la estructura de las bases de datos del stage:

lambdaorm pull
Opción Descripción
-w, --workspace Carpeta del proyecto (por defecto: la carpeta actual).
-s, --stage Nombre del stage (por defecto: el primer stage).
-e, --envfile Archivo de variables de entorno que se lee.

Pull también escribe, en la carpeta orm_state, el modelo del stage y el DDL de la estructura obtenida, en una carpeta por fuente. El DDL es un registro: no se ejecuta.

Archivos creados:

├── orm_state
│   ├── default-model.json
│   └── default
│       └── V240501212640__pull.sql

Node

orm.stage.pull() actualiza el archivo del esquema con la estructura de las bases de datos del stage:

import { Orm } from '@lambdaorm/lib'
(async () => {
    const orm = new Orm()
    try {
        await orm.init('./lambdaORM.yaml')
        await orm.stage.pull({ stage: 'default' })
    } catch (e) {
        console.log(e)
    } finally {
        await orm.end()
    }
})()
