Variables de entorno en el esquema

Esta página muestra cómo usar variables de entorno en el esquema, para mantener las conexiones y los secretos fuera del archivo del esquema.

Cualquier valor del esquema se puede tomar de una variable de entorno, con la notación $VARIABLE o ${VARIABLE}. Las variables se reemplazan al cargar el esquema. Con la CLI, la opción -e las lee de un archivo (por ejemplo -e .env).

Ejemplos

Conexión a la base de datos

La conexión de cada fuente se lee de una variable de entorno:

infrastructure:
  sources:
    - name: source1
      dialect: MySQL
      mapping: mapping1
      connection: $CNN_MYSQL
    - name: source2
      dialect: PostgreSQL
      mapping: mapping2
      connection: $CNN_POSTGRES

La variable contiene la conexión en formato JSON:

CNN_MYSQL={"host":"localhost","port":3306,"user":"test","password":"test","database":"test"}
CNN_POSTGRES={"host":"localhost","port":5433,"user":"test","password":"test","database":"test"}

Clave de las funciones de cifrado

La clave que usan encrypt y decrypt se lee de una variable de entorno, dentro de una expresión:

domain:
  entities:
    ...
    - name: Users
      extends: Basics
      primaryKey: ["username"]
      uniqueKey: ["email"]
      properties:
        - name: username
          length: 32
          required: true
        - name: firstname
          required: true
        - name: lastname
          required: true
        - name: email
          required: true
          length: 255
          writeValue: encrypt(lower(email),"${USERS_SECRET_KEY}")
          readValue: decrypt(email,"${USERS_SECRET_KEY}")
    ...
