CLI de λORM

La CLI de λORM (@lambdaorm/cli) es una aplicación de línea de comandos para usar λORM: crea proyectos, sincroniza las bases de datos con el esquema, importa y exporta datos, y ejecuta consultas y scripts. Sus comandos se ejecutan localmente con un workspace (-w), y la mayoría también se puede ejecutar en un Data Gateway (-u <url>).

Instalación

Se instala el paquete de forma global; añade el comando lambdaorm:

npm i -g @lambdaorm/cli
lambdaorm --version

Requiere Node.js 20 o posterior. La imagen Docker del Data Gateway (flaviorita/data-gateway) ya incluye la CLI.

Nota

El paquete sin scope lambdaorm-cli es el antiguo y ya no se mantiene.

Comandos

Comando Descripción
version Imprime la versión de la CLI y la versión de @lambdaorm/lib que usa el proyecto.
init Genera la estructura de un proyecto λORM.
build Genera el modelo y los repositorios para el lenguaje.
schema Devuelve información sobre el esquema.
push Sincroniza las bases de datos con el modelo (-o escribe los scripts en su lugar).
pull Actualiza el esquema con la estructura de las bases de datos de un stage.
fetch Muestra las diferencias entre las bases de datos y el modelo; termina con código 1 cuando hay alguna.
introspect Lee y analiza un archivo de datos y actualiza el esquema.
incorporate Actualiza el esquema a partir de un archivo de datos, aplica los cambios en las bases de datos e importa los datos.
drop Elimina todos los objetos de base de datos, pero no la base de datos en sí.
import Importa datos de un archivo a las bases de datos.
export Exporta datos de las bases de datos.
execute Ejecuta una consulta.
script Ejecuta un script: varias consultas en una sola transacción.
plan Devuelve el plan de ejecución de una consulta.
metadata Devuelve los metadatos de una consulta.
parameters Devuelve los parámetros de una consulta.
model Devuelve el modelo del resultado de una consulta.
constraints Devuelve las restricciones de una consulta.

lambdaorm <command> -h lista las opciones de un comando; lambdaorm -h lista los comandos.

El comando sync ya no existe: fue reemplazado por push.

Opciones comunes

Opción Corta Descripción
workspace -w Ruta del proyecto (la carpeta con lambdaORM.yaml). Por defecto: el directorio actual.
stage -s Nombre del stage. Por defecto: el primer stage del esquema.
envfile -e Lee un archivo de variables de entorno (por ejemplo, las cadenas de conexión).
output -o Formato de salida del resultado: json, beautiful, light o yaml.
url -u URL del esquema en un Data Gateway, para ejecutar el comando allí en lugar de localmente.

La página de cada comando lista las opciones que ese comando acepta.

Código de salida y Data Gateway

Todos los comandos terminan con código 1 cuando fallan (desde @lambdaorm/cli 1.6.3).

Los comandos se ejecutan en un Data Gateway con -u y la URL del esquema, por ejemplo http://gateway:8080/iot/v1. Cuando la variable de entorno SERVICE_TOKEN está definida, se envía como Authorization: Bearer <token> (para un gateway con autenticación bearer). Ver también Clientes.
