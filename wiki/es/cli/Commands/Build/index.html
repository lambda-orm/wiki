Build

Genera el código fuente del dominio para el lenguaje de desarrollo: el modelo (model.ts, con las entidades y enumeraciones) y un repositorio por entidad (repository<Entity>.ts). Ver Repositorios.

Un archivo de repositorio solo se genera si todavía no existe, de modo que se conserva el código propio que se le haya añadido; el modelo se regenera cada vez.

Opciones

Opción Corta Descripción
workspace -w Ruta del proyecto.
language -l Lenguaje de desarrollo: node (por defecto, usa @lambdaorm/lib) o client-node (usa @lambdaorm/client; el dominio se lee del Data Gateway indicado en infrastructure.service.url del esquema, tal como lo escribe init -u).
model -m Genera el modelo.
repositories -r Genera los repositorios.
all -a Genera el modelo y los repositorios (es el valor por defecto cuando no se indica ninguna de -m, -r, -a).
src-path Ruta relativa del código fuente en el workspace (--src-path).
data-path Ruta relativa de la carpeta de datos en el workspace (--data-path).
domain-path Ruta relativa del dominio dentro de la ruta del código fuente (--domain-path).
url -u URL del esquema en un Data Gateway.

Ejemplo

lambdaorm build -w lab/countries
