Características

Una introducción a lo que ofrece λORM, con enlaces a las páginas que describen cada característica.

Motores de base de datos

  • MySQL, MariaDB, PostgreSQL, SQL Server, Oracle, MongoDB y SQLite (SQLjs).
  • Una sola consulta puede involucrar varias bases de datos, incluso de motores distintos.
  • Motores de base de datos: las diferencias entre motores (tipos, cadenas vacías, upsert, …).

Lenguaje de consultas

  • Lenguaje de consultas basado en expresiones lambda de JavaScript.
  • Las consultas se pueden escribir como código JavaScript/TypeScript o como una cadena.
  • Cláusulas select, insert, inserción masiva, update y delete.
  • Joins y agrupaciones implícitos.
  • Carga anticipada (eager loading) de relaciones con include, también entre bases de datos.
  • Operadores y funciones.
  • Metadatos de consultas: los parámetros, el modelo, las restricciones y el plan de ejecución de una consulta.

Uso

  • Repositorios y repositorios personalizados.
  • Transacciones y transacciones distribuidas, entre fuentes y stages.
  • Scripts: un caso de uso completo (variables, condiciones, bucles y varias consultas) en una sola transacción, también a través del Data Gateway.
  • Ejemplos de uso: una sola fuente, varias fuentes, CQRS y el cliente de Node.js.

Esquema

  • Configuración del esquema que desacopla el modelo de dominio de la infraestructura.
  • Configuración en JSON o YAML.
  • Mappings entre el dominio y la infraestructura.
  • Herencia de entidades (extends).
  • Variables de entorno.
  • Índices, claves únicas y restricciones.
  • Condiciones y acciones basadas en el motor de expresiones 3xpr (expresiones).
  • Stages: varios escenarios de infraestructura para el mismo dominio.
  • Sincronización entre el esquema y las bases de datos: push, pull, fetch, introspect e incorporate.
  • Listeners y subscribers: se esperan (await) y se ejecutan en la transacción de la sentencia que los dispara.

Rendimiento

  • Inserción masiva.
  • Consultas de alto rendimiento.
  • Pool de conexiones.

Herramientas y clientes

  • Soporte para TypeScript y JavaScript.
  • CLI (npm i -g @lambdaorm/cli, comando lambdaorm).
  • Data Gateway (imagen Docker flaviorita/data-gateway):
    • una API REST, MCP para agentes de IA y una API WebSocket, con varios esquemas por instancia;
    • credenciales con permisos, auditoría de escrituras, métricas y health checks;
    • una UI web: explorador, formularios de entidades, consultas guardadas y diagramas del dominio.
  • Clientes:
    • cliente de Node.js (@lambdaorm/client, REST o WebSocket);
    • otros lenguajes: generar un cliente a partir del documento OpenAPI 3 del Data Gateway.
