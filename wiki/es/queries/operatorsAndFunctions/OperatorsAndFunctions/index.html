Operadores y funciones

Las consultas de λORM son expresiones lambda, y dentro de ellas se pueden usar los operadores y funciones que se enumeran en esta referencia. λORM traduce cada uno al lenguaje del motor de base de datos de la fuente de datos: SQL para MySQL, MariaDB, PostgreSQL, SQL Server, Oracle y SQLite, y pipelines de agregación para MongoDB. Ver Lenguaje de consultas para una introducción a las consultas.

Cada página describe los operadores y funciones de una categoría, con su firma, una consulta de ejemplo, su resultado y el SQL generado para ella. No todas las funciones se pueden traducir a todos los motores de base de datos; cada página termina con una sección Soporte por base de datos que enumera las diferencias.

Consejo

Para comprobar cómo se traduce una consulta para una fuente de datos determinada sin ejecutarla, se usa orm.plan.
