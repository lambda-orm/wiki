    Expresiones lambda¶

    Esta página resume las piezas de una consulta de λORM: los métodos que se encadenan sobre una entidad y los operadores y funciones que se pueden usar dentro de las lambdas. Sirve como referencia rápida; cada método enlaza con la página de sus ejemplos.

    Las consultas son expresiones lambda escritas en el propio lenguaje de programación. Hacen referencia a las entidades y propiedades del dominio, por lo que son independientes del lenguaje de la base de datos y de cómo se almacenan los datos.

    Ejemplo¶

    La siguiente consulta lee los productos cuyo nombre empieza por "A", con el nombre de su categoría, ordenados por categoría (ascendente) y producto (descendente), y devuelve la primera página de 10 registros:

    Products
    .filter(p => upper(substr(p.name, 1, 1)) == "A")
    .map(p => ({ category: p.category.name, product: p.name }))
    .sort(p => [p.category, desc(p.product)])
    .page(1, 10)

    En Oracle, λORM la traduce a:

    SELECT c.CategoryName AS "category", p.ProductName AS "product"
FROM Products p
INNER JOIN Categories c ON c.CategoryID = p.CategoryID
WHERE UPPER(SUBSTR(p.ProductName,1,1)) = 'A'
ORDER BY "category" asc, "product" desc
OFFSET 0 ROWS FETCH NEXT 10 ROWS ONLY

    La misma consulta se ejecuta en cualquier otro motor de base de datos: en MySQL, por ejemplo, la paginación se convierte en LIMIT 0,10.

    Ventajas¶

    • Las consultas se escriben en el mismo lenguaje de programación que la aplicación.
    • No hay que aprender un lenguaje nuevo.
    • Las expresiones son fáciles de escribir y de leer.
    • El IntelliSense del IDE ayuda a escribir las expresiones.
    • Los errores de sintaxis se detectan mientras se escribe.

    Métodos de consulta¶

    Método Descripción Equivalente SQL Ejemplos
    filter Filtra los registros. WHERE Select
    having Filtra los grupos. HAVING Agrupación
    map Indica las propiedades a devolver. SELECT Select
    distinct Indica las propiedades a devolver, eliminando los registros duplicados. SELECT DISTINCT Select
    first Devuelve el primer registro. SELECT + ORDER BY + LIMIT Select
    last Devuelve el último registro. SELECT + ORDER BY DESC + LIMIT Select
    sort Indica el orden de los registros. ORDER BY Select
    page Pagina los registros. LIMIT / OFFSET (depende del dialecto) Select
    include Carga los registros de entidades relacionadas. Include
    insert Inserta un registro. INSERT Insert
    upsert Inserta un registro, o lo actualiza si ya existe uno con la misma clave primaria. INSERT … ON CONFLICT / MERGE Insert
    bulkInsert Inserta muchos registros a la vez. INSERT Inserción masiva
    update Actualiza registros; siempre tiene un filtro. UPDATE con WHERE Update
    updateAll Actualiza todos los registros de una entidad. UPDATE sin WHERE Update
    delete Elimina registros; siempre tiene un filtro. DELETE con WHERE Delete
    deleteAll Elimina todos los registros de una entidad. DELETE sin WHERE Delete
    • No hay un método para los joins: se deduce un INNER JOIN cuando la consulta navega por una relación, como en p.category.name (ver Join).
    • No hay un método para GROUP BY: se deduce cuando se usa una función de agregación (ver Agrupación).
